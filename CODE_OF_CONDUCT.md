# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful in issues, pull requests, and discussions.

Report unacceptable behavior to the maintainer through [GitHub's private report form](https://github.com/venvk/obsidian-library-plugin/security/advisories/new).
