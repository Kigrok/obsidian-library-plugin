# AGENTS.md

Guidance for AI agent working with code in this repo.

## Project

Obsidian plugin ("Library"), renders notes as card gallery. TypeScript in `src/` bundled to `main.js` (CJS) by esbuild. Working dir **is** installed plugin folder inside vault → `npm run dev` writes `main.js` in place, Obsidian loads it after plugin reload.

## Commands

- `npm run dev` — esbuild watch build.
- `npm run build` — `tsc -noEmit -skipLibCheck` + minified `main.js`. Required gate before PR.
- `npm run lint` — eslint on `src/**/*.ts` + `tests/**/*.ts` (typescript-eslint `recommendedTypeChecked` + `eslint-plugin-obsidianmd`). `vitest.config.ts` ignored: outside root `tsconfig`, project service can't type it without dragging vitest types into production `tsc` gate.
- `npm test` (`npm run test:watch`) — vitest, `tests/**/*.test.ts`, jsdom.
- `npm version <x.y.z>` — lifecycle script syncs `manifest.json` + `versions.json` from `package.json`, stages them; never hand-edit three version fields. Pushing tag triggers `.github/workflows/release.yml` → builds, attests, publishes release.

## Tests

`tests/unit/` covers pure helpers + providers. `tests/compliance/` guards Obsidian submission rules (manifest, versions, license, source hygiene, README privacy table), ends with bundle smoke test: rebuilds `src/main.ts` with esbuild, evaluates with shim `require('obsidian')`, boots plugin against `tests/stubs/obsidian.ts` (npm `obsidian` package types-only, so `vitest.config.ts` aliases module to stub). `tests/setup.ts` installs Obsidian DOM helpers (`createEl`/`createDiv`/`setText`/…) and restores Node's `TextEncoder`/`Uint8Array` — jsdom realm breaks esbuild startup invariant check.

ES2017 type ceiling applies to `src/` only: `tests/tsconfig.json` raises `lib` to ES2020, uses `moduleResolution: bundler`. Node-only types and `document`-based helpers fine in tests; eslint config relaxes mobile/DOM rules for `tests/**`.

## Constraints that are easy to violate

- **ES2017 = type ceiling.** `tsconfig.json` `lib` stops at ES2017 → ES2018+ runtime APIs (`Object.fromEntries`, `Array.prototype.flat`, `String.prototype.trimEnd`) fail build though esbuild targets es2020. Use loop or regex.
- **Obsidian API ceiling 1.8.7** (`minAppVersion`), but `obsidian` dep is `latest` → typings accept APIs missing at min version. Check docs version, not typings.
- **All network calls use `requestUrl` from `obsidian`, never global `fetch`** — plugin targets mobile (`isDesktopOnly: false`).
- **Every UI string through `tr()`** (`src/i18n.ts`). Add key to **all** locale blocks in `I18N` (`src/constants.ts`), not just `en`; `localeMap` there maps Obsidian language subtags to blocks. Count strings use `trCount(key, n)` + three keys `<key>1` / `<key>2` / `<key>5` (singular / plural / Slavic-Baltic "many"); form picked by `Intl.PluralRules`, never hand-written number rules; `{count}` in text filled. Write count as label (`Removed: {count}`) or via `trCount` — never `note(s)`. Locale block stays in own script: key parity alone passed while `zh-TW` and `pt-BR` held Tatar strings → `tests/unit/i18n.test.ts` also checks script of every value.
- **`Genre`, `Creator`, `Cast` are link properties** (`LINK_FIELDS` in `src/main.ts`): hold `[[Name]]` entries so each genre/creator/actor note lists titles as backlinks and graph draws them. Writes via `toLinks()` (`src/util.ts`); `syncLinkFields` converts plain names (hand-typed or from earlier version) to links, keeps user-written links (aliases incl.), removes `Related` property of earlier versions. Anything *showing* these values (header, statistics, share card) unwraps via `linkLabel()`.
- **Frontmatter = untrusted data.** Any value becoming `href` or `src` goes through `safeUrl()` (`src/util.ts`, http/https only) — shared note must not plant `javascript:` link. Names becoming files/links go through `sanitizeFilename()` / `sanitizeLink()`.
- **DOM plugin injects into Obsidian's own views removed in `onunload`** (note header in reading views, gallery lightbox); registered events + timers alone not enough.
- **Frontmatter field names = data contract** (`Source`, `Source ID`, `Progress` as `watched/total`, `Date` as `dd.mm.yyyy`, `My Rating`, `Rating IMDB`). Renaming one silently breaks refresh, statistics, AniList sync on existing notes. `Trailer` (link), `Gallery` (image URL list), `Seasons` (list of `{name, episodes, rating, trailer}`, series only), `Runtime` (minutes; series = length of **one** episode), `Cast` (top-billed actors of movie/series, from OMDb `Actors`) = optional additions from metadata enrichment — same "fill empty only" rule on refresh, hand edits win. Series note shows whole run: `totalRuntimeMinutes` (`src/util.ts`) multiplies stored per-episode value by `Seasons` episode sum, fallback `Progress` denominator; `formatRuntime` (same file) renders as `header.hours` + `header.minutes` — minutes alone unreadable past an hour. Stats view watch-time donut sums `watchedRuntimeMinutes` (watched episodes × per-episode length, whole run once `Complete` set) for `movie`/`series`/`anime` categories.
- **Episode tracking lives in `Seasons`** (`src/episodes.ts`): each season may carry `my_rating` + `episode_list` of `{title, watched, my_rating}`. Until any episode has `watched` boolean, first N episodes (N = Progress numerator, or all when `Complete`) count watched → older notes keep progress. First tick writes all episodes out; after that ticks drive `Progress`, `Complete`, and `My Rating` (average of season ratings; season = avg of rated episodes, else own `my_rating`). Refresh merges source season list via `mergeSeasons` instead of fill-empty-only → new seasons/titles arrive, ticks + ratings stay. Anything else moving Progress forward (AniList pull, Complete switch) calls `followProgress`. Books keep same `{title, watched, my_rating}` entries in `Chapters` (one implicit season); once present `Progress` counts chapters (`hasChapters`), and `setChapters` carries pages read over as same share. Titles come from Open Library table of contents (`findChapters`, same-script edition preferred), else typed in `ChaptersModal`.
- **Metadata enrichment keyless by default.** `src/providers/cinemeta.ts` (IMDb-id-keyed, no account) fills `Trailer`/`Gallery`/`Seasons`/`Runtime` for movies + series; AniList fills `Trailer`/`Gallery` for anime. `src/providers/tmdb.ts` = optional richer source, applied first when TMDB key set. OMDb always wins on shared keys. Enrichers implement `MetadataEnricher` (`src/providers/types.ts`), injected into `OmdbProvider` in order — never register one as `ContentProvider`.
- **New fields reach existing notes via background pass, not migration.** `scheduleEnrich` (`src/main.ts`) walks vault 10 s after `onLayoutReady`, one note per 700 ms, stamps `settings.enrichMarks[path] = manifest.version` once note refreshed → release backfills whole library itself, later launches quiet. Note stamped only on successful fetch (quota error/outage leaves it for next pass); offline device stops pass early; provider with nothing to refetch by id says so via `refreshable()` (Open Library); finished pass drops marks of deleted notes. Marks cleared in `saveSettings` when API-key signature changes (`apiKeySignature`) — new key unlocks data previous pass couldn't fetch; key changed mid-pass sets `enrichAgain` → walk restarts after it ends. Scheduling timer (`enrichTimer`) and step pause (`enrichSleepTimer`) stay separate: one shared timer → key change cancels pause, walk hangs. `Refresh metadata of all notes` command runs same walk forced. Pass abortable: `onunload` sets `unloaded`, resolves pending sleep; bundle smoke test asserts no timer survives.
- **View state surviving reload lives in settings file**, not module scope: `settings.sortState` per category, `settings.statsCollapsed` for statistics section, `collapsed: true` on folded category (read on `render`, written back via `persistSettings()` on user action). `settings.stats` holds watch-time switch + `tops`, ordered list of statistics columns — each a category (keyed by Type value) or frontmatter property (by name); `loadStats` converts earlier-version switches into that list. Nested settings blocks merged key by key in `loadSettings`; `onExternalSettingsChange` reloads file when sync changes it — without it next save here overwrites other device's changes.
- **Settings tab described once** (`sections()` in `src/settings.ts`): `getSettingDefinitions()` renders rows on Obsidian 1.13+ and feeds global settings search; `display()` draws same rows before 1.13 → never drift. 1.13-only call (`update()`, `refreshDomState()`) sits behind `requireApiVersion("1.13.0")` with version as string literal — `obsidianmd/no-unsupported-api` recognises only that form; unguarded call = error in community review. Row names unique within group (Obsidian keys rows by name) → each category own group. Row with neither name nor control renders only via `render` callback (`note()`).
- **Library view redraws only for library notes** (and notes shown last time); redraw keeps scroll position + folded sections.
- **`main.js` generated + gitignored** — never edit or commit.

## Adding a content source

Implement `ContentProvider` and `ContentType` from `src/providers/types.ts`, keep `Source ID` stable as refresh key, register provider in `src/main.ts`.

Two sources feeding same medium → merge behind aggregator, not second category (`src/providers/bookAggregator.ts`, `src/providers/gameAggregator.ts`): aggregator tags each search result with `{__pid, __raw}` so `fetch` routes back to right source; on refresh (no raw result) falls back to source-id shape (Steam ids prefixed `steam:`; Open Library ids start with `/`; bare numeric ids = RAWG).

## Style and repo etiquette

- Tabs for indentation (`.editorconfig`); strict TypeScript, no `any`.
- Conventional Commits with version in message, e.g. `feat: 2.2.1 — AniList progress sync`. PRs target `main`.
- User-facing changes usually also need updating 30 translated READMEs under `readme/` alongside `README.md`. Commands + buttons appear there under translated names — take from that locale's `I18N` block, since command palette searches translated name.
