## Возможности

- **Визуальная сетка карточек** — Вкладка «Библиотека» отображает коллекцию как галерею обложек.
- **Встроенный поиск** — Ищите и добавляйте произведения прямо в приложении: OMDb для фильмов и сериалов, Open Library или Google Books для книг, RAWG/Steam для игр, Deezer для музыки, AniList для аниме, Comic Vine для комиксов.
- **Умный подсчёт серий** — Сезоны и количество серий подтягиваются автоматически и синхронизируются.
- **Индикаторы прогресса** — Визуальные полоски прогресса на карточках и заголовках заметок показывают, сколько вы посмотрели или прочитали.
- **Информативные заголовки** — Каждая заметка получает автоматически сгенерированный заголовок со всеми ключевыми метаданными.
- **Трейлеры, кадры и сезоны** — В заметках о фильмах и сериалах отображаются встроенный трейлер YouTube/Vimeo, ряд кадров и длительность; у сериалов также список сезонов с количеством серий, оценками и трейлерами по сезонам.
- **Пользовательские категории** — Создавайте категории для фильмов, сериалов, аниме, комиксов, книг, игр, музыки или чего угодно через ручной ввод.
- **Связи графа** — Жанры, создатели и актёры хранятся ссылками в собственных свойствах `Genre`, `Creator` и `Cast`, поэтому заметка каждого жанра, создателя и актёра собирает свои произведения в обратных ссылках, а граф показывает все связи.
- **Карточки для публикации** — Превратите любую контентную заметку в готовое к публикации изображение-карточку (постер, название, год, жанр, рейтинг IMDb и ваша оценка) и опубликуйте её в X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky или Pinterest — отправьте прямо в приложения на устройстве или скопируйте/сохраните изображение для использования где угодно.
- **Синхронизация с AniList** — Отправляйте прогресс, статус и оценку аниме прямо в свой аккаунт AniList или подтягивайте свой список обратно в заметки.
- **Сортировка и свёртывание** — Сортируйте карточки по названию, году, рейтингу или дате; сворачивайте любую категорию — она останется свёрнутой после перезапуска.
- **Статистика** — Колонки выбираете вы: произведения категории с лучшей оценкой или самые частые значения любого свойства (жанры, создатели, актёры…), плюс диаграмма времени просмотра.
- **Поиск дубликатов** — Автоматически предотвращает повторное добавление одного произведения по URL. Встроенная команда находит и удаляет существующие дубликаты.
- **Мультиязычность** — интерфейс плагина переведён на **все языки, которые поддерживает Obsidian** (70+), поэтому он всегда совпадает с языком вашего Obsidian. Полные переводы README есть для 30 из них (см. панель языков вверху).

## Быстрый старт

### 1. Установка

Установите **Library** из каталога плагинов Obsidian (Настройки > Плагины сообщества > Обзор > поиск «Library») или вручную через [GitHub Releases](https://github.com/Kigrok/obsidian-library-plugin/releases).

### 2. Настройка

1. Перейдите в **Настройки** > **Library**.
2. Добавьте **категории** — выберите готовый тип (Фильмы, Сериалы, Книги, Комиксы, Игры, Музыка, Аниме или Вручную) из выпадающего списка и нажмите «Добавить категорию». Каждая категория имеет отображаемое имя (на вашем языке), значение `Type` (всегда английское, например `Movie`), источник и необязательную папку для хранения заметок.
3. _(Необязательно)_ Введите API-ключи для нужных сервисов: [OMDb](https://www.omdbapi.com/apikey.aspx) для фильмов/сериалов, [RAWG](https://rawg.io/apidocs) для игр, [Comic Vine](https://comicvine.gamespot.com/api/) для комиксов, [TMDB](https://www.themoviedb.org/settings/api) для трейлеров, кадров и сведений о сезонах, а также ключ [Google Books](https://console.cloud.google.com/apis/library/books.googleapis.com) для поиска книг. Для аниме (AniList), музыки (Deezer) и Steam ключ не нужен.

### 3. Добавление карточки по названию

Больше не нужно заполнять фронтматер вручную — добавьте фильм, сериал, книгу, аниме или комикс просто по названию:

1. Откройте вкладку **«Библиотека»** по иконке в ленте (или командой «Открыть библиотеку»).
2. Нажмите кнопку **+** в правом верхнем углу (или команду «Добавить контент»).
3. Выберите категорию, введите название в поисковую строку и выберите результат.
4. Карточка создаётся мгновенно — постер, год, жанр, создатели и рейтинг заполняются автоматически.

Кнопка **«Поиск по библиотеке»** рядом с **+** ищет уже добавленные произведения.

Для категорий **«Вручную»** просто введите название и заполните обложку, год и другие поля сами.

## Статистика

Вверху вкладки «Библиотека» сворачиваемый раздел **Статистика** показывает выбранные вами колонки:

- **Топы категорий** — три произведения категории с лучшей оценкой, с обложками: *Топ фильмов*, *Топ книг* и так далее. Сортировка по `My Rating`, а без неё — по `Rating IMDB`.
- **Топы свойств** — три самых частых значения свойства по всей библиотеке: *Топ жанров*, *Топ создателей*, *Топ актёров* или любое другое свойство, например *Топ: Author*. `Sci-Fi`, `sci-fi` и `[[Sci-Fi]]` считаются одним значением.
- **Время просмотра** — диаграмма часов, потраченных на фильмы, сериалы и аниме, по полям `Runtime` и `Progress` каждой заметки.

Настраивается в **Настройки → Library → Статистика**: **Добавить топ** предлагает ваши категории и свойства, найденные в заметках, кнопка корзины убирает колонку, а переключатель скрывает диаграмму времени просмотра. Колонки идут в порядке добавления; новая категория сразу добавляет свой топ.

Свёрнутые категории остаются свёрнутыми после перезапуска.

## Поиск дубликатов

Library предотвращает дублирование, проверяя поле `URL`:

- **При добавлении** — если заметка с таким URL уже существует, открывается существующая вместо создания дубликата.
- **Найти и удалить дубли** — запустите эту команду из палитры для сканирования всех заметок, группировки по URL и выборочного удаления.

## Источники

Каждая категория привязана к источнику, который обеспечивает поиск:

| Источник | Типы контента | API-ключ |
| --- | --- | --- |
| **OMDb** | Фильмы, Сериалы | Нужен бесплатный ключ — [omdbapi.com](https://www.omdbapi.com/apikey.aspx) |
| **Books** | Книги | Open Library (без ключа) + Google Books (необязательный бесплатный ключ). Результаты объединяются. |
| **Games** | Игры | RAWG (нужен бесплатный ключ — [rawg.io/apidocs](https://rawg.io/apidocs)) + Steam (без ключа) — Результаты объединяются. |
| **Deezer** | Музыка (альбомы) | Без ключа |
| **AniList** | Аниме | Без ключа — бесплатное GraphQL API AniList, ключ не нужен |
| **Comic Vine** | Комиксы | Нужен бесплатный ключ — [comicvine.gamespot.com/api](https://comicvine.gamespot.com/api/) |
| **Вручную** | Любое | Без ключа — вводите название и заполняете поля сами |

Заметки о фильмах и сериалах получают трейлер, кадры, длительность и список сезонов **без всяких ключей** — через Cinemeta. Необязательный ключ **TMDB** добавляет более богатые данные (оценки сезонов, больше кадров).

## Конфиденциальность и сеть

Library работает **автономно**: ваша библиотека — это обычные заметки, и она работает без подключения к сети. Плагин отправляет только перечисленные ниже данные и только в этих случаях:

- **Когда вы действуете сами:** ищете произведение, обновляете метаданные, запускаете команду AniList или нажимаете кнопку публикации.
- **Когда вы открываете заметку библиотеки:** её метаданные обновляются из источника по `Source ID` — не чаще одного раза в 5 минут для каждой заметки; заметка без `Source ID` ищется по названию.
- **После обновления плагина или смены API-ключа:** фоновый проход один раз обновляет заметки библиотеки из их источников — по одной заметке за раз.

Обложки, кадры и плееры трейлеров, на которые ссылаются ваши заметки, загружаются с перечисленных ниже хостов.

| Сервис | Когда | Что отправляется | Зачем |
| --- | --- | --- | --- |
| `www.omdbapi.com` | Поиск по OMDb | Название и API-ключ | Метаданные фильмов/сериалов |
| `openlibrary.org` | Поиск по Open Library | Название | Метаданные книг |
| `covers.openlibrary.org` | У книги есть обложка | ID обложки | Загрузка изображения |
| `www.googleapis.com` | Поиск по Google Books | Название и ключ | Метаданные книг |
| `api.rawg.io` | Поиск игр по RAWG | Название и ключ | Метаданные игр |
| `api.deezer.com` | Поиск музыки по Deezer | Альбом или исполнитель | Метаданные альбомов |
| `graphql.anilist.co` | Поиск в категории аниме | Введённое название | Получение метаданных аниме (название, год, жанр, количество серий, оценка AniList, студия, постер) |
| `graphql.anilist.co` | Запуск команды синхронизации с AniList | Ваш токен доступа AniList и прогресс, статус и оценка заметки | Чтение или обновление вашего списка аниме в AniList |

| `comicvine.gamespot.com` | Поиск комиксов | Название и ключ | Метаданные комиксов |
| `store.steampowered.com` | Вы ищете или добавляете игру Steam | Введённое название или ID приложения Steam | Получение метаданных игры (год, жанр, разработчик, обложка) |
| `cdn.cloudflare.steamstatic.com` | У карточки игры Steam есть обложка | ID приложения Steam | Загрузка обложки |
| `api.themoviedb.org` | Вы добавляете или обновляете заметку о фильме/сериале и указали ключ TMDB | ID IMDb из заметки и ваш ключ TMDB | Загрузка трейлера, кадров, длительности и списка сезонов сериала |
| `image.tmdb.org` | У заметки о фильме/сериале есть кадры | Путь к изображению TMDB | Загрузка кадров |
| `v3-cinemeta.strem.io` | Вы добавляете или обновляете заметку о фильме или сериале | ID IMDb из заметки | Загрузка трейлера, кадров, длительности и списка сезонов сериала — ключ не нужен |
| `images.metahub.space` | У заметки о фильме или сериале есть кадры | ID IMDb из заметки | Загрузка кадров (фонов) |
| `episodes.metahub.space` | У заметки о сериале есть кадры эпизодов | ID IMDb сериала и номера сезона и эпизода | Загрузка кадров эпизодов |
| `i.ytimg.com` | В заметке о фильме показаны кадры трейлера | ID видео трейлера | Загрузка кадров трейлера |
| `s4.anilist.co` | У заметки об аниме есть баннер | Путь к изображению на CDN AniList | Загрузка изображения баннера |
| `www.youtube.com`, `www.youtube-nocookie.com`, `player.vimeo.com`, `www.dailymotion.com` | Вы открываете заметку с трейлером | ID трейлера | Встраивание плеера трейлера |
| `twitter.com`, `t.me`, `wa.me`, `www.reddit.com`, `www.facebook.com`, `www.linkedin.com`, `vk.com`, `bsky.app`, `www.pinterest.com` | Вы нажимаете кнопку публикации | Подпись карточки (название, ваша оценка, ссылка на источник) | Открытие окна публикации выбранной сети с заполненным постом — само изображение карточки остаётся локальным |

Больше никакие данные не покидают ваше хранилище. Плагин не имеет телеметрии, аналитики и автообновления. API-ключи (OMDb, Google Books, RAWG, Comic Vine, TMDB) хранятся только в локальных настройках и отправляются только соответствующим сервисам.

## Схема фронтматера

Плагин читает и записывает стандартный YAML-фронтматер. Заметки создаются автоматически, но каждое поле можно отредактировать. `Source` и `Source ID` позволяют плагину обновлять метаданные позже.

### Фильм

> **Свойство обложки** — свойство frontmatter, в котором хранится обложка, можно переименовать в **Настройки → Library** (например, на `image`); существующие заметки продолжат работать.

```yaml
---
Type: Movie
Name: Начало
Year: 2010
Genre:
    - "[[боевик]]"
    - "[[фантастика]]"
Creator:
    - "[[Кристофер Нолан]]"
Cast:
    - "[[Леонардо Ди Каприо]]"
    - "[[Джозеф Гордон-Левитт]]"
    - "[[Эллиот Пейдж]]"
Rating IMDB: 8.8
Rating RT: 87
Runtime: 148
My Rating: 9
Cover: https://m.media-amazon.com/images/...
URL: https://www.imdb.com/title/tt1375666/
Trailer: https://www.youtube.com/watch?v=YoHD9XEInc0
Gallery:
    - https://image.tmdb.org/t/p/w780/9e3Dz7H1J0s5cBZLX2yXKxkC7Jg.jpg
Progress: 1/1
Complete: true
Date: 01.03.2026
Source: omdb
Source ID: tt1375666
---
```

> **Автообновление сериалов:** Запустите «Обновить метаданные текущей заметки» (или просто откройте заметку) — плагин обновит общее количество серий в `Progress` и количество сезонов, сохранив ваш счётчик просмотренных.

> **Трейлер, кадры и сезоны:** Плагин автоматически заполняет `Trailer`, `Gallery`, `Runtime` и (для сериалов) `Seasons` — ключ не нужен (необязательный ключ TMDB добавляет оценки сезонов и больше кадров). `Runtime` — это длительность фильма в минутах или количество минут на серию для сериала. Тогда в заголовке заметки отображаются встроенный плеер, ряд кадров и список сезонов с количеством серий, оценками и кнопками трейлеров для каждого сезона. Каждое поле — обычный фронтматер: отредактируйте или удалите его, и плагин при следующем обновлении не тронет ваши значения. Каждая новая версия плагина также один раз обходит библиотеку в фоне и добирает добавленные ею поля — по одной заметке, не мешая работе.

## Связи графа

Жанры, создатели и — у фильмов и сериалов — актёры хранятся ссылками в собственных свойствах:

```yaml
Genre:
    - "[[Action]]"
    - "[[Sci-Fi]]"
Creator:
    - "[[Christopher Nolan]]"
Cast:
    - "[[Leonardo DiCaprio]]"
```

Поэтому в обратных ссылках заметки каждого жанра, создателя и актёра видны все его произведения, а граф связывает заметки через них. Обычные названия — набранные вручную или оставшиеся от прежней версии — превращаются в ссылки при любом изменении заметки; ссылка с псевдонимом остаётся как есть. `Перестроить связи для графа` переводит всю библиотеку разом. Свойство `Related` из прежних версий больше не используется и удаляется из заметок.

## Публикация

Каждая контентная заметка получает кнопку **«Поделиться»** в заголовке (или запустите `Поделиться текущей заметкой`). Она рендерит изображение-карточку — постер, название, год, жанр, рейтинг IMDb/AniList и вашу оценку — которое можно опубликовать где угодно:

- **На мобильном** — кнопка **«Поделиться…»** открывает системное меню общего доступа с уже прикреплённым изображением карточки, чтобы вы могли отправить его прямо в любое приложение.
- **X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky, Pinterest** — открывает редактор поста в выбранной сети с заранее заполненной подписью (название, ваша оценка, ссылка на источник и ссылка на этот плагин). Изображение карточки одновременно копируется в буфер обмена, так что вам остаётся лишь вставить его (Ctrl/Cmd+V) в пост.
- **Копировать изображение / Копировать текст / Сохранить изображение** — скопируйте готовую карточку или подпись в буфер обмена либо сохраните изображение в папку вложений хранилища, чтобы прикрепить вручную.

Публикация полностью локальна: карточка рисуется внутри приложения из собственных метаданных и обложки заметки. Ничего не загружается на сервер — плагин лишь открывает выбранный вами URL редактора в браузере.

## Синхронизация с AniList

Держите прогресс по аниме синхронизированным с вашим аккаунтом [AniList](https://anilist.co).

**Настройка** — в **Настройки → Library → Синхронизация с AniList**:

1. Зарегистрируйте бесплатный API-клиент на [anilist.co/settings/developer](https://anilist.co/settings/developer), указав в качестве redirect URL `https://anilist.co/api/v2/oauth/pin`.
2. Вставьте **Client ID**, нажмите **Подключить** и авторизуйтесь.
3. AniList покажет вам токен доступа — вставьте его в плагин. Нажмите **Проверить подключение**, чтобы убедиться, что всё работает.

Затем используйте команды:

- **Отправить текущую заметку в AniList** — отправляет прогресс активной заметки об аниме (просмотренные серии), статус (смотрю / просмотрено / запланировано) и вашу оценку в ваш список AniList.
- **Загрузить прогресс из AniList** — получает ваш список аниме из AniList и обновляет соответствующие заметки. Загрузка работает **только вперёд**: оно никогда не откатывает заметку, которая локально продвинулась дальше или уже завершена, и не трогает вашу личную оценку `My Rating`.

Синхронизируются только заметки с `Source: anilist` (добавленные через источник аниме AniList). Ваш токен хранится локально в настройках плагина и отправляется только в AniList.
