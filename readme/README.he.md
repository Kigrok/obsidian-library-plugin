## תכונות עיקריות

- **רשת כרטיסים ויזואלית** — לשונית ספרייה ייעודית המציגה את האוסף שלך כגלריה של כרטיסי עטיפות.
- **חיפוש מובנה** — חפש והוסף כותרים ישירות בתוך האפליקציה: OMDb לסרטים וסדרות, Open Library או Google Books לספרים, RAWG/Steam למשחקים, Deezer למוזיקה, AniList לאנימה, Comic Vine לקומיקסים.
- **מעקב חכם אחר סדרות** — עונות ומספר פרקים נמשכים אוטומטית ומתעדכנים.
- **מחווני התקדמות** — סרגלי התקדמות ויזואליים על כרטיסים וכותרות הערות מראים כמה צפית או קראת.
- **כותרות הערות עשירות** — כל הערת תוכן מקבלת כותרת שנוצרה אוטומטית עם כל מטה-נתונים מרכזיים.
- **טריילרים, תמונות ועונות** — הערות של סרטים וסדרות מציגות טריילר מוטמע מ-YouTube/Vimeo, שורת תמונות ומשך; סדרות מקבלות גם רשימת עונות עם מספר פרקים, דירוגים וטריילרים לכל עונה.
- **קטגוריות מותאמות אישית** — צור קטגוריות לסרטים, סדרות, אנימה, קומיקסים, ספרים, משחקים, מוזיקה או כל דבר אחר דרך המקור הידני.
- **קישורי תרשים** — ז'אנרים, יוצרים ושחקנים נשמרים כקישורים במאפיינים משלהם `Genre`, `Creator` ו-`Cast`, כך שהערה של כל ז'אנר, יוצר ושחקן אוספת את הכותרים שלו בקישורים החוזרים, והגרף מציג הכול.
- **כרטיסי שיתוף** — הפוך כל הערת תוכן לתמונת כרטיס לשיתוף (פוסטר, כותרת, שנה, ז'אנר, דירוג IMDb והדירוג שלך) ופרסם אותה ל-X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky או Pinterest — שתף אותה ישירות לאפליקציות של המכשיר שלך, או העתק/שמור את התמונה לשימוש בכל מקום.
- **סנכרון AniList** — דחוף את ההתקדמות, הסטטוס והדירוג של האנימה שלך ישירות לחשבון AniList שלך, או משוך את הרשימה שלך בחזרה להערות שלך.
- **מיון וקיפול** — מיין כרטיסים לפי שם, שנה, דירוג או תאריך; קפל כל קטגוריה — היא נשארת מקופלת גם אחרי הפעלה מחדש.
- **סטטיסטיקות** — בחר בעצמך את העמודות: היצירות בעלות הדירוג הגבוה ביותר בכל קטגוריה או הערכים הנפוצים ביותר של כל מאפיין (ז'אנרים, יוצרים, שחקנים…), ובנוסף תרשים של זמן הצפייה.
- **זיהוי כפילויות** — מונע אוטומטית הוספת אותו כותר פעמיים לפי כתובת URL. פקודה מובנה מוצאת ומוחקת כפילויות קיימות.
- **רב-לשוני** — ממשק התוסף מתורגם **לכל השפות ש-Obsidian תומך בהן** (יותר מ-70), כך שהוא תמיד תואם לשפת ה-Obsidian שלך. תרגום מלא של ה-README זמין ל-30 מהן (ראה את סרגל השפות למעלה).

## התחלה מהירה

### 1. התקנה

התקן את **הספרייה** מ-[מדריך התוספים הקהילתיים של Obsidian](https://community.obsidian.md/plugins/library) (הגדרות > תוספים קהילתיים > דפדף > חפש "Library"), או התקן ידנית דרך [גרסאות GitHub](https://github.com/Kigrok/obsidian-library-plugin/releases).

### 2. הגדרה בסיסית

1. עבור אל **הגדרות** > **הספרייה**.
2. הוסף את **הקטגוריות שלך** — בחר סוג מוגדר מראש (סרטים, סדרות, ספרים, קומיקסים, משחקים, מוזיקה, אנימה, או ידני) מהתפריט הנפתח ולחץ על **הוסף קטגוריה**. לכל קטגוריה יש שם תצוגה (מתורגם לשפתך), ערך `Type` (תמיד באנגלית, למשל `Movie`), מקור, ותיקייה אופציונלית לשמירת הערות.
3. _(אופציונלי)_ הזן מפתחות API לשירותים בהם אתה משתמש: [OMDb](https://www.omdbapi.com/apikey.aspx) לסרטים/סדרות, [RAWG](https://rawg.io/apidocs) למשחקים, [Comic Vine](https://comicvine.gamespot.com/api/) לקומיקסים, [TMDB](https://www.themoviedb.org/settings/api) עבור טריילרים, תמונות ופרטי עונות, ומפתח [Google Books](https://console.cloud.google.com/apis/library/books.googleapis.com) לחיפוש ספרים. אנימה (AniList), מוזיקה (Deezer) ו-Steam אינם דורשים מפתח.

### 3. הוספת כותרת

למלא את הנתונים הידנית הוא עבר — הוסף סרט, סדרה, ספר, אנימה או קומיקס רק על ידי חיפוש השם שלו:

1. פתח את לשונית **הספרייה** מאייקון הסרגל (או הרץ `פתח את הספרייה`).
2. לחץ על כפתור **+** בצד ימין למעלה של דף הספרייה (או הרץ `הוסף תוכן`).
3. בחר קטגוריה, הקלד את **הכותרת** בתיבת החיפוש, ובחר תוצאה.
4. כותרת נוצרת באופן מיידי, עם פוסטר, שנה, ז'אנרים, יוצרים ודירוג שממולאים אוטומטית.

כפתור **חיפוש** ליד **+** מחפש כותרים שכבר נמצאים בספרייה שלך.

לקטגוריות **ידניות** אתה פשוט מקליד כותר וממלא את העטיפה, השנה ושדות אחרים ידנית.

## סטטיסטיקות

בראש הכרטיסייה „ספרייה” מקטע **סטטיסטיקות** המתקפל מציג את העמודות שבחרת:

- **מובילי קטגוריה** — שלוש היצירות בעלות הדירוג הגבוה ביותר בקטגוריה, עם עטיפות: *סרטים מובילים*, *ספרים מובילים* וכן הלאה. המיון לפי `My Rating`, ובהיעדרו לפי `Rating IMDB`.
- **מובילי מאפיין** — שלושת הערכים הנפוצים ביותר של מאפיין בכל הספרייה: *ז'אנרים מובילים*, *יוצרים מובילים*, *שחקנים מובילים* או כל מאפיין אחר, למשל *מובילים: Author*. `Sci-Fi`, `sci-fi` ו-`[[Sci-Fi]]` נספרים כערך אחד.
- **זמן צפייה** — תרשים של השעות שהוקדשו לסרטים, לסדרות ולאנימה, מחושב מהשדות `Runtime` ו-`Progress` של כל פתק.

ההגדרה נמצאת ב-**הגדרות → Library → סטטיסטיקות**: **הוספת רשימת מובילים** מציג את הקטגוריות שלך ואת המאפיינים שנמצאו בפתקים, סמל הפח מסיר עמודה, ומתג מסתיר את תרשים זמן הצפייה. העמודות מופיעות בסדר ההוספה; קטגוריה חדשה מוסיפה גם את רשימת המובילים שלה.

קטגוריות מקופלות נשארות מקופלות אחרי הפעלה מחדש.

## זיהוי כפילויות

הספרייה מונעת רשומות כפולות על ידי בדיקת שדה `URL`:

- **בהוספה** — אם הערה עם כתובת URL זהה כבר קיימת, היא פותח את הערה הקיימת במקום ליצור כפילות.
- **מצוא והסר כפילויות** — הרץ פקודה זו מהפלטה לסריקת כל הערות, קיבוץ לפי URL, והסרת כפילויות נבחרות דרך מודאל.

## פרטיות ושימוש ברשת

הספרייה היא **אופליין תחילה**: הספרייה שלך היא הערות רגילות והיא ממשיכה לעבוד גם ללא חיבור. התוסף שולח רק את הנתונים המפורטים להלן, ורק במקרים האלה:

- **כשאתה פועל בעצמך:** אתה מחפש כותר, מרענן מטה-נתונים, מריץ פקודת AniList או לוחץ על כפתור השיתוף.
- **כשאתה פותח הערה מהספרייה:** המטה-נתונים שלה מתרעננים מהמקור לפי `Source ID`, לכל היותר פעם ב-5 דקות לכל הערה; הערה ללא `Source ID` מחופשת לפי השם שלה.
- **אחרי עדכון של התוסף או שינוי של מפתח API:** מעבר ברקע מרענן פעם אחת את הערות הספרייה שלך מהמקורות שלהן, הערה אחת בכל פעם.

תמונות עטיפה, תמונות סטילס ונגני טריילרים שההערות שלך מפנות אליהם נטענים מהשרתים המפורטים להלן.

## סכמת נתונים קדמית

התוסף קורא וכותב לנתוני YAML קדמיים סטנדרטיים. הערות נוצרות עבורך, אך כל שדה ניתן לעריכה. `Source` ו-`Source ID` מאפשרים לתוסף לעדכן מטה-נתונים מאוחר יותר.

### סרט

> **מאפיין עטיפה** — את מאפיין ה-frontmatter שמאחסן את העטיפה אפשר לשנות ב**הגדרות ← Library** (למשל ל-`image`); הערות קיימות ימשיכו לעבוד.

```yaml
---
Type: Movie
Name: Inception
Year: 2010
Genre:
    - "[[Action]]"
    - "[[Sci-Fi]]"
Creator:
    - "[[Christopher Nolan]]"
Cast:
    - "[[Leonardo DiCaprio]]"
    - "[[Joseph Gordon-Levitt]]"
    - "[[Elliot Page]]"
Rating IMDB: 8.8
Rating RT: 87
Runtime: 148
My Rating: 9
Cover: https://m.media-amazon.com/images/...
URL: https://www.imdb.com/title/tt1375666/

Gallery:
    - https://image.tmdb.org/t/p/w780/9e3Dz7H1J0s5cBZLX2yXKxkC7Jg.jpg
```

> **עדכון אוטומטי של סדרה:** הרץ `רענן מטא-נתונים של הפתק הנוכחי` (או פשוט פתח את ההערה) והתוסף מעדכן את ספירת הפרקים הכוללת ב-`Progress` (למשל מ-`25/42` ל-`25/50`) וספירת `Season`, תוך שמירה על ספירת הצפייה שלך שלמה.

> **טריילר, תמונות ועונות:** כאשר מוגדר מפתח TMDB, התוסף ממלא אוטומטית `Trailer`, `Gallery`, `Runtime` ו(עבור סדרות) `Seasons` — `Runtime` הוא אורך הסרט בדקות, או הדקות לפרק בסדרה. לאחר מכן כותרת ההערה מציגה נגן מוטמע, שורת תמונות ורשימת עונות עם מספר פרקים, דירוגים וכפתורי טריילר לכל עונה. כל שדה הוא נתונים קדמיים רגילים: ערוך או מחק אותו והתוסף לא ייגע בערכים שלך ברענון הבא. בנוסף, כל גרסה חדשה של התוסף מריצה סריקה אחת ברקע שמשלימה את השדות החדשים — פתק אחר פתק, בלי לחסום את האפליקציה.

## קישורי תרשים

ז'אנרים, יוצרים ובסרטים ובסדרות גם שחקנים נשמרים כקישורים במאפיינים משלהם:

```yaml
Genre:
    - "[[Action]]"
    - "[[Sci-Fi]]"
Creator:
    - "[[Christopher Nolan]]"
Cast:
    - "[[Leonardo DiCaprio]]"
```

כך הערה של כל ז'אנר, יוצר ושחקן מציגה בקישורים החוזרים את כל הכותרים שלו, והגרף מחבר דרכם בין ההערות. שמות רגילים — שהוקלדו ידנית או נשארו מגרסה קודמת — הופכים לקישורים בכל שינוי של ההערה; קישור עם כינוי נשאר כמו שהוא. `בנה מחדש קישורי גרף` ממיר את כל הספרייה בבת אחת. המאפיין `Related` מגרסאות קודמות כבר לא בשימוש ומוסר מההערות.

## שיתוף

כל הערת תוכן מקבלת כפתור **שיתוף** בכותרת שלה (או הרץ `שתף את הפתק הנוכחי`). הוא מרנדר תמונת כרטיס — פוסטר, כותרת, שנה, ז'אנר, דירוג IMDb/AniList והדירוג שלך — שאתה יכול לפרסם בכל מקום:

- **בנייד** — כפתור **שיתוף…** פותח את גיליון השיתוף המובנה של המכשיר שלך עם תמונת הכרטיס מצורפת ישירות, כך שתוכל לשלוח אותה ישר לכל אפליקציה.
- **X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky, Pinterest** — פותח את חלון הכתיבה של הרשת עם כיתוב מוכן מראש (כותרת, הדירוג שלך, קישור המקור וקישור לתוסף זה). תמונת הכרטיס מועתקת ללוח שלך בו-זמנית, כך שאתה רק מדביק אותה (Ctrl/Cmd+V) לתוך הפוסט.
- **העתק תמונה / העתק טקסט / שמור תמונה** — העתק את הכרטיס המרונדר או את הכיתוב ללוח, או שמור את התמונה לתיקיית הקבצים המצורפים של הכספת שלך לצירוף ידני.

השיתוף מקומי לחלוטין: הכרטיס מצויר בתוך האפליקציה מהמטה-נתונים ומהעטיפה של ההערה עצמה. שום דבר לא מועלה — התוסף רק פותח את כתובת ה-URL של חלון הכתיבה שבחרת בדפדפן שלך.

## סנכרון AniList

שמור על סנכרון התקדמות האנימה שלך עם חשבון [AniList](https://anilist.co) שלך.

**הגדרה** — ב-**הגדרות → הספרייה → סנכרון AniList**:

1. רשום לקוח API חינם ב-[anilist.co/settings/developer](https://anilist.co/settings/developer), עם כתובת ההפניה מוגדרת ל-`https://anilist.co/api/v2/oauth/pin`.
2. הדבק את ה-**Client ID**, לחץ על **התחבר**, ואשר.
3. AniList מציג לך אסימון גישה — הדבק אותו בתוסף. לחץ על **בדוק חיבור** כדי לאשר.

לאחר מכן השתמש בפקודות:

- `שלח את הפתק הנוכחי ל-AniList` — שולח את ההתקדמות של הערת האנימה הפעילה (פרקים שנצפו), הסטטוס (בצפייה / הושלם / מתוכנן) והדירוג שלך לרשימת AniList שלך.
- `משוך התקדמות מ-AniList` — מאחזר את רשימת האנימה שלך ב-AniList ומעדכן הערות תואמות. המשיכה היא **קדימה בלבד**: היא לעולם לא מסיגה לאחור הערה שמתקדמת יותר באופן מקומי או שכבר הושלמה, והיא משאירה את ה-`My Rating` האישי שלך ללא שינוי.

רק הערות עם `Source: anilist` (שנוספו דרך מקור האנימה של AniList) מסונכרנות. האסימון שלך מאוחסן מקומית בהגדרות התוסף ונשלח רק ל-AniList.

## פקודות

| פקודה | תיאור |
| --- | --- |
| `פתח את הספרייה` | פתח את לשונית גלריית הספרייה. |
| `הוסף תוכן` | חפש מקור וצור הערת תוכן (או הקלד כותר לידני). |
| `חפש בספרייה שלך` | חיפוש מטושטש ופתח כל הערה שכבר נמצאת בספרייה שלך. |
| `רענן מטא-נתונים של הפתק הנוכחי` | משוך מחדש מטה-נתונים עבור הערה פעילה; מעדכן ספירת פרקים בסדרות. |
| `בנה מחדש קישורי גרף` | הופך את `Genre`, `Creator` ו-`Cast` לקישורים בכל הערות התוכן. |
| `מצא והסר כפולים` | סרוק כל הערה לפי URL, הצג כפילויות, והסר נבחרות. |
| `שתף את הפתק הנוכחי` | רנדר את ההערה כתמונת כרטיס ושתף אותה ל-X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky או Pinterest. |
| `שלח את הפתק הנוכחי ל-AniList` | שלח את ההתקדמות, הסטטוס והדירוג של הערת האנימה הפעילה לחשבון AniList שלך. |
| `משוך התקדמות מ-AniList` | אחזר את רשימת AniList שלך ועדכן הערות תואמות (קדימה בלבד). |
| `רענן מטא-נתונים של כל הפתקים` | אחזר מטא-נתונים של כל הפתקים בספרייה — אחד בכל פעם, ברקע. |
