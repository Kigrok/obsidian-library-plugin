## Основні можливості

- **Візуальна сітка карток** — Спеціальна вкладка Library відображає вашу колекцію як галерею карток з обкладинками.
- **Вбудований пошук** — Шукайте та додавайте назви прямо в додатку: OMDb для фільмів та серіалів, Open Library або Google Books для книг, RAWG для ігор, Deezer для музики, AniList для аніме, Comic Vine для коміксів.
- **Розумне відстеження серіалів** — Сезони та загальна кількість серій автоматично отримуються та підтримуються в синхронізації.
- **Індикатори прогресу** — Візуальні смуги прогресу на картках та заголовках нотаток показують, скільки ви переглянули або прочитали.
- **Багаті заголовки нотаток** — Кожна нотатка контенту отримує автоматично згенерований заголовок з усіма ключовими метаданими.
- **Користувацькі категорії** — Створюйте категорії для фільмів, серіалів, аніме, коміксів, книг, ігор, музики або чого завгодно через ручне джерело.
- **Посилання графа** — Властивість `Related` у frontmatter з'єднує кожну нотатку з її категорією, жанрами та творцями, автоматично підтримується в синхронізації для красивого графа.
- **Картки для поширення** — Перетворіть будь-яку нотатку контенту на картку-зображення для поширення (постер, назва, рік, жанр, оцінка IMDb та ваш рейтинг) та опублікуйте її в X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky або Pinterest — поділіться нею прямо в додатках вашого пристрою, або скопіюйте/збережіть зображення, щоб використати будь-де.
- **Синхронізація з AniList** — Надсилайте прогрес, статус та рейтинг аніме прямо на свій акаунт AniList або завантажуйте свій список назад у свої нотатки.
- **Сортування та згортання** — Сортуйте картки за назвою, роком, рейтингом або датою; згортайте будь-яку категорію.
- **Статистика** — Найкращі жанри, найкращі творці (тільки фільми та серіали) та найкращі елементи за категорією з медальними рейтингами.
- **Виявлення дублікатів** — Автоматично запобігає додаванню того ж самого запису двічі за URL. Вбудована команда знаходить та видаляє існуючі дублікати.
- **Багатомовність** — 31 мова: англійська, українська, російська, білоруська, казахська, узбецька, німецька, іспанська, французька, італійська, нідерландська, чеська, хорватська, польська, румунська, турецька, азербайджанська, перська, хінді, бенгальська, урду, тагальська, в'єтнамська, тайська, яванська, японська, корейська, китайська, арабська, сингальська, іврит.

## Швидкий старт

### 1. Встановлення

Встановіть **Library** з [каталогу Obsidian Community Plugins](https://community.obsidian.md/plugins/library) (Налаштування > Community plugins > Огляд > шукайте "Library") або встановіть вручну через [GitHub Releases](https://github.com/Kigrok/obsidian-library-plugin/releases).

### 2. Базова настройка

1. Перейдіть до **Налаштування** > **Library**.
2. Додайте свої **Категорії** — виберіть попередньо визначений тип (Movies, Series, Books, Comics, Games, Music, Anime або Manual) з випадаючого меню та натисніть **Add category**. Кожна категорія має назву для відображення (перекладену вашою мовою), значення `Type` (завжди англійською, напр. `Movie`), джерело та необов'язкову теку для зберігання нотаток.
3. _(Необов'язково)_ Введіть API-ключі для сервісів, які ви використовуєте: [OMDb](https://www.omdbapi.com/apikey.aspx) для фільмів/серіалів, [RAWG](https://rawg.io/apidocs) для ігор, [Comic Vine](https://comicvine.gamespot.com/api/) для коміксів. Аніме (AniList) та музика (Deezer) не потребують ключа.

### 3. Додайте картку за назвою

Більше не потрібно вручну заповнювати frontmatter — додайте фільм, серіал, книгу, аніме або комікс просто пошукавши його назву:

1. Відкрийте вкладку **Library** з іконки на панелі (або запустіть `Open Library`).
2. Натисніть кнопку **+** у верхньому правому куті сторінки Library (або запустіть `Add content`).
3. Виберіть категорію, введіть **назву** в поле пошуку та виберіть результат.
4. Картка створюється миттєво, з постером, роком, жанром, творцями та рейтингом, автоматично заповненими.

Кнопка **Search** поруч з **+** шукає назви, які вже є у вашій бібліотеці.

Для категорій **Manual** просто введіть назву та самі заповніть обкладинку, рік та інші поля.

## Статистика

Вкладка Library містить згортуваний розділ **Statistics** вгорі:

- **Найкращі жанри** — ранжовані за частотою у всій вашій бібліотеці.
- **Найкращі творці** — ранжовані за кількістю фільмів та серіалів, у яких вони з'являються.
- **Найкращі за категорією** — для кожної категорії (Movies, Series, Books тощо) топ-3 елементів за рейтингом з маленькими мініатюрами обкладинок.

## Виявлення дублікатів

Library запобігає дублікатам, перевіряючи поле `URL`:

- **При додаванні** — якщо нотатка з таким самим URL вже існує, вона відкриває існуючу нотатку замість створення дубліката.
- **Знайдіть та видаліть дублікати** — запустіть цю команду з палітри для сканування всіх нотаток, групування за URL та вибіркового видалення дублікатів через модальне вікно.

## Конфіденційність та використання мережі

Library є **offline-first**. Плагін з'єднується з мережею тільки коли ви активно шукаєте назву для додавання, і тільки з пошуковими запитами, які ви вводите:

| Сервіс | Коли | Що відправляється | Чому |
| --- | --- | --- | --- |
| `www.omdbapi.com` | Ви шукаєте категорію на основі OMDb | Назва, яку ви вводите, та ваш API-ключ OMDb | Отримання метаданих фільму/серіалу (рік, жанри, акторський склад, рейтинг, постер, кількість серій) |
| `openlibrary.org` | Ви шукаєте категорію Open Library | Назва, яку ви вводите | Отримання метаданих книги (автор, рік, теми, ID обкладинки) |
| `covers.openlibrary.org` | Картка книги має обкладинку | ID обкладинки Open Library | Завантаження зображення обкладинки |
| `www.googleapis.com` | Ви шукаєте категорію Google Books | Назва, яку ви вводите, та ваш ключ Google Books | Отримання метаданих книги (автор, рік, категорії, кількість сторінок, обкладинка, ISBN) |
| `api.rawg.io` | Ви шукаєте категорію ігор RAWG | Назва, яку ви вводите, та ваш ключ RAWG | Отримання метаданих гри (рік, жанри, розробник, обкладинка) |
| `api.deezer.com` | Ви шукаєте категорію музики Deezer | Альбом або виконавець, якого ви вводите | Отримання метаданих альбому (виконавець, рік, жанри, кількість треків, обкладинка) |
| `graphql.anilist.co` | Ви шукаєте категорію аніме | Назва, яку ви вводите | Отримання метаданих аніме (назва, рік, жанри, серії, оцінка AniList, студія, постер) |
| `graphql.anilist.co` | Ви запускаєте команду синхронізації з AniList | Ваш токен доступу AniList та прогрес, статус і рейтинг нотатки | Читання або оновлення вашого списку аніме AniList |
| `comicvine.gamespot.com` | Ви шукаєте категорію коміксів | Назва, яку ви вводите, та ваш ключ Comic Vine | Отримання метаданих коміксу (назва, рік, видавець, кількість випусків, обкладинка) |

Жодні інші дані ніколи не залишають ваш vault. Плагін **не має телеметрії, аналітики та механізму автоматичного оновлення**. API-ключі (OMDb, Google Books, RAWG, Comic Vine) зберігаються тільки у ваших локальних налаштуваннях плагіна та відправляються тільки відповідним сервісам. Зображення обкладинок завантажуються безпосередньо з URL, які повертаються кожним джерелом.

## Схема Frontmatter

Плагін читає та пише у стандартний YAML frontmatter. Нотатки створюються для вас, але кожне поле можна редагувати. `Source` та `Source ID` дозволяють плагіну оновити метадані пізніше.

### Movie

```yaml
---
Type: Movie
Name: Inception
Year: 2010
Genre:
    - Action
    - Sci-Fi
Creator:
    - Christopher Nolan
Rating IMDB: 8.8
My Rating: 9
Cover: https://m.media-amazon.com/images/...
URL: https://www.imdb.com/title/tt1375666/
Progress: 1/1
Complete: true
Date: 01.03.2026
Source: omdb
Source ID: tt1375666
---
```

### Series

```yaml
---
Type: Series
Name: Stranger Things
Year: 2016
End Year: 2025
Season: 5
Genre:
    - Drama
    - Fantasy
    - Horror
Creator:
    - The Duffer Brothers
Rating IMDB: 8.7
My Rating: 9
Cover: https://m.media-amazon.com/images/...
URL: https://www.imdb.com/title/tt4574334/
Progress: 25/42
Complete: false
Date: 01.03.2026
Source: omdb
Source ID: tt4574334
---
```

> **Автоматичне оновлення серіалів:** Запустіть `Refresh metadata for current note` (або просто відкрийте нотатку), і плагін оновить загальну кількість серій у `Progress` (напр., `25/42` на `25/50`) та кількість `Season`, зберігши вашу кількість переглянутих без змін.

### Book

```yaml
---
Type: Book
Name: Dune
Year: 1965
Genre:
    - Science Fiction
Creator:
    - Frank Herbert
Cover: https://covers.openlibrary.org/b/id/...-L.jpg
ISBN: 9780441013593
My Rating: 9
Progress: 412/688
Complete: false
Date: 01.03.2026
Source: openlibrary
Source ID: /works/OL893415W
---
```

### Anime

```yaml
---
Type: Anime
Name: Steins;Gate
Year: 2011
Genre:
    - Sci-Fi
    - Thriller
Creator:
    - White Fox
Rating AniList: 9.1
Status: FINISHED

URL: https://anilist.co/anime/9253
Progress: 0/24
Complete: false
Date: 01.03.2026
Source: anilist
Source ID: 9253
---
```

### Comic

```yaml
---
Type: Comic
Name: Watchmen

    - DC Comics

Complete: false
Date: 01.03.2026
Source: comicvine
Source ID: 33819
---
```

## Посилання графа

Кожна нотатка контенту отримує властивість `Related` у frontmatter, автоматично оновлювану — тіло нотатки ніколи не змінюється:

```yaml
Related:
    - "[[Movie]]"
    - "[[Action]]"
    - "[[Sci-Fi]]"
    - "[[Christopher Nolan]]"
```

Ці посилання з'єднують ваші нотатки через спільні категорії, жанри та творців, тому перегляд графа Obsidian формує чисті кластери. Справжня нотатка-хаб створюється для кожної категорії (напр. `Movie`), тому кластери показуються навіть з прихованими невирішеними посиланнями. Властивість записується при створенні нотатки та оновлюється при кожній зміні її метаданих — запустіть `Rebuild graph links` тільки якщо ви хочете примусити повне відновлення.

## Поширення

Кожна нотатка контенту отримує кнопку **Share** у своєму заголовку (або запустіть `Share current note`). Вона рендерить картку-зображення — постер, назва, рік, жанр, оцінка IMDb/AniList та ваш рейтинг — яку ви можете опублікувати будь-де:

- **На мобільному** — кнопка **Share…** відкриває нативне вікно поширення вашого пристрою з безпосередньо прикріпленим зображенням картки, тож ви можете надіслати його прямо в будь-який додаток.
- **X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky, Pinterest** — відкриває редактор мережі з попередньо заповненим підписом (назва, ваш рейтинг, посилання на джерело та посилання на цей плагін). Зображення картки водночас копіюється у ваш буфер обміну, тож вам залишається лише вставити його (Ctrl/Cmd+V) у публікацію.
- **Copy image / Copy text / Save image** — скопіюйте відрендерену картку чи підпис у буфер обміну, або збережіть зображення в теку вкладень вашого vault, щоб прикріпити вручну.

Поширення повністю локальне: картка малюється всередині додатка з власних метаданих та обкладинки нотатки. Нічого не завантажується на сервер — плагін лише відкриває обраний вами URL редактора у вашому браузері.

## Синхронізація з AniList

Тримайте прогрес аніме синхронізованим зі своїм акаунтом [AniList](https://anilist.co).

**Налаштування** — у **Налаштування → Library → Синхронізація з AniList**:

1. Зареєструйте безкоштовний API-клієнт на [anilist.co/settings/developer](https://anilist.co/settings/developer), вказавши redirect URL `https://anilist.co/api/v2/oauth/pin`.
2. Вставте **Client ID**, натисніть **Connect** та авторизуйтесь.
3. AniList покаже вам токен доступу — вставте його в плагін. Натисніть **Test connection**, щоб підтвердити.

Далі використовуйте команди:

- `Push current note to AniList` — надсилає прогрес активної нотатки аніме (переглянуті серії), статус (переглядаю / завершено / заплановано) та ваш рейтинг у ваш список AniList.
- `Pull progress from AniList` — отримує ваш список аніме з AniList та оновлює відповідні нотатки. Завантаження працює **тільки вперед**: воно ніколи не відкочує нотатку, яка локально просунулась далі або вже завершена, і не змінює ваш особистий `My Rating`.

Синхронізуються лише нотатки з `Source: anilist` (додані через джерело аніме AniList). Ваш токен зберігається локально в налаштуваннях плагіна та надсилається лише до AniList.

## Команди

| Команда                              | Опис                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------ |

| `Rebuild graph links`               | З'єднайте кожну нотатку контенту з її категорією, жанрами та творцями.     |
| `Find & remove duplicates`          | Скануйте всі нотатки за URL, покажіть дублікати та видаліть вибрані.      |
| `Share current note`                 | Відрендерте нотатку як картку-зображення та поділіться нею в X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky або Pinterest. |
| `Push current note to AniList`       | Надішліть прогрес, статус та рейтинг активної нотатки аніме на свій акаунт AniList. |
| `Pull progress from AniList`         | Отримайте свій список AniList та оновіть відповідні нотатки (тільки вперед). |
