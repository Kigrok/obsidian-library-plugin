## الميزات الرئيسية

- **شبكة بطاقات بصرية** — علامة تبويب مكتبة مخصصة تعرض مجموعتك كمعرض من بطاقات أغلفة الفن.
- **بحث مدمج** — ابحث عن العناوين وأضفها مباشرة داخل التطبيق: OMDb للأفلام والمسلسلات، أو Open Library أو Google Books للكتب، أو RAWG/Steam للألعاب، أو Deezer للموسيقى، أو AniList للأنمي، أو Comic Vine للكوميكس.
- **تتبع ذكي للمسلسلات** — يتم جلب مواسم وعدد الحلقات تلقائيًا وإبقاؤها متزامنة.
- **مؤشرات التقدم** — شرائط التقدم المرئية على البطاقات وترويسات الملاحظات تُظهر كم شاهدت أو قرأت.
- **ترويسات ملاحظات غنية** — كل ملاحظة محتوى تحصل على ترويسة مولّدة تلقائيًا بجميع البيانات الوصفية الرئيسية.
- **المقاطع الدعائية والصور والمواسم** — تعرض ملاحظات الأفلام والمسلسلات مقطعًا دعائيًا مضمّنًا من YouTube/Vimeo وصفًا من الصور والمدة؛ كما تحصل المسلسلات على قائمة مواسم بعدد الحلقات والتقييمات ومقاطع دعائية لكل موسم.
- **فئات مخصصة** — أنشئ فئات للأفلام والمسلسلات والأنمي والكوميكس والكتب والألعاب والموسيقى أو أي شيء آخر عبر المصدر اليدوي.
- **روابط الرسم البياني** — تُحفظ الأنواع والمبدعون والممثلون روابطَ في خصائصها `Genre` و`Creator` و`Cast`، فتجمع ملاحظة كل نوع ومبدع وممثل أعماله في الروابط الخلفية ويعرض الرسم البياني كل شيء.
- **بطاقات المشاركة** — حوّل أي ملاحظة محتوى إلى صورة بطاقة قابلة للمشاركة (الملصق، العنوان، السنة، النوع، تقييم IMDb، وتقييمك الخاص) وانشرها على X أو Telegram أو Reddit أو WhatsApp أو Facebook أو LinkedIn أو VK أو Bluesky أو Pinterest — شاركها مباشرة إلى تطبيقات جهازك، أو انسخ/احفظ الصورة لاستخدامها في أي مكان.
- **مزامنة AniList** — ادفع تقدّم الأنمي وحالته وتقييمه مباشرةً إلى حساب AniList الخاص بك، أو اسحب قائمتك إلى ملاحظاتك.
- **الترتيب والطي** — رتّب البطاقات حسب الاسم أو السنة أو التقييم أو التاريخ، واطوِ أي فئة — وتبقى مطوية بعد إعادة التشغيل.
- **الإحصائيات** — اختر الأعمدة بنفسك: الأعمال الأعلى تقييمًا في أي فئة أو القيم الأكثر تكرارًا لأي خاصية (الأنواع، المبدعون، الممثلون…)، إضافة إلى مخطط وقت المشاهدة.
- **اكتشاف التكرار** — يمنع تلقائيًا إضافة العنوان نفسه مرتين حسب الرابط. أمر مدمج يعثر على التكرارات القائمة ويحذفها.
- **متعدد اللغات** — واجهة الإضافة مترجمة إلى **جميع اللغات التي يدعمها Obsidian** (أكثر من 70)، لذا تطابق دائمًا لغة Obsidian لديك. تتوفر ترجمة كاملة لملف README إلى 30 منها (انظر شريط اللغات في الأعلى).

## البدء السريع

### 1. التثبيت

ثبّت **المكتبة** من [دليل الإضافات المجتمعية لـ Obsidian](https://community.obsidian.md/plugins/library) (الإعدادات > الإضافات المجتمعية > تصفح > ابحث عن "Library")، أو ثبّته يدويًا عبر [إصدارات GitHub](https://github.com/Kigrok/obsidian-library-plugin/releases).

### 2. الإعداد الأساسي

1. انتقل إلى **الإعدادات** > **المكتبة**.
2. أضف **فئاتك** — اختر نوعًا محددًا مسبقًا (أفلام، مسلسلات، كتب، كوميكس، ألعاب، موسيقى، أنمي، أو يدوي) من القائمة المنسدلة وانقر على **إضافة فئة**. كل فئة لها اسم عرض (مترجم إلى لغتك)، وقيمة `Type` (دائمًا بالإنجليزية، مثل `Movie`)، ومصدر، ومجلد اختياري لتخزين الملاحظات.
3. _(اختياري)_ أدخل مفاتيح API للخدمات التي تستخدمها: [OMDb](https://www.omdbapi.com/apikey.aspx) للأفلام والمسلسلات، [RAWG](https://rawg.io/apidocs) للألعاب، [Comic Vine](https://comicvine.gamespot.com/api/) للكوميكس، [TMDB](https://www.themoviedb.org/settings/api) للمقاطع الدعائية والصور وتفاصيل المواسم، ومفتاح [Google Books](https://console.cloud.google.com/apis/library/books.googleapis.com) للبحث عن الكتب. الأنمي (AniList) والموسيقى (Deezer) وSteam لا تحتاج إلى مفتاح.

### 3. إضافة بطاقة بالعنوان

لا ملء البيانات الأمامية يدويًا بعد الآن — أضف فيلمًا أو مسلسلًا أو كتابًا أو أنميًا أو كوميكًا بمجرد البحث عن اسمه:

1. افتح علامة تبويب **المكتبة** من أيقونة الشريط (أو نفّذ أمر `فتح المكتبة`).
2. انقر على زر **+** في أعلى يمين صفحة المكتبة (أو نفّذ أمر `إضافة محتوى`).
3. اختر فئة، واكتب **العنوان** في مربع البحث، واختر نتيجة.
4. يتم إنشاء بطاقة فورًا، مع ملء الملصق والسنة والأنواع والمنشئين والتقييم تلقائيًا.

زر **البحث** بجوار **+** يبحث عن العناوين الموجودة بالفعل في مكتبتك.

لفئات **اليدوية**، ما عليك سوى كتابة عنوان وملء الغلاف والسنة والحقول الأخرى يدويًا.

## الإحصائيات

في أعلى علامة التبويب «المكتبة» يعرض قسم **الإحصائيات** القابل للطي الأعمدة التي تختارها:

- **الأفضل في الفئة** — الأعمال الثلاثة الأعلى تقييمًا في الفئة مع أغلفتها: *أفضل الأفلام* و*أفضل الكتب* وغيرها. يعتمد الترتيب على `My Rating`، وإلا فعلى `Rating IMDB`.
- **الأكثر تكرارًا في الخاصية** — القيم الثلاث الأكثر تكرارًا لخاصية ما في مكتبتك كلها: *أفضل الأنواع* و*أفضل المبدعين* و*أفضل الممثلين* أو أي خاصية أخرى مثل *الأفضل: Author*. تُعدّ `Sci-Fi` و`sci-fi` و`[[Sci-Fi]]` قيمة واحدة.
- **وقت المشاهدة** — مخطط للساعات التي قضيتها في الأفلام والمسلسلات والأنمي، محسوبة من حقلي `Runtime` و`Progress` في كل ملاحظة.

يُضبط ذلك من **الإعدادات → Library → الإحصائيات**: يعرض **إضافة قائمة الأفضل** فئاتك والخصائص الموجودة في ملاحظاتك، وتزيل أيقونة سلة المهملات العمود، ويُخفي مفتاح التبديل مخطط وقت المشاهدة. تظهر الأعمدة بترتيب إضافتها، وكل فئة جديدة تضيف قائمتها تلقائيًا.

تبقى الفئات المطوية مطوية بعد إعادة التشغيل.

## اكتشاف التكرار

تمنع المكتبة الإدخالات المكررة بالتحقق من حقل `URL`:

- **عند الإضافة** — إذا كانت ملاحظة بنفس الرابط موجودة بالفعل، تفتح الملاحظة الموجودة بدلاً من إنشاء تكرار.
- **البحث عن التكرارات وإزالتها** — نفّذ هذا الأمر من لوحة الأوامر لفحص جميع الملاحظات، وتجميعها حسب الرابط، وإزالة التكرارات المحددة عبر نافذة منبثقة.

## المصادر

| المصدر | أنواع المحتوى | مفتاح API |
| --- | --- | --- |
| **OMDb** | أفلام، مسلسلات | مفتاح مجاني مطلوب — [omdbapi.com](https://www.omdbapi.com/apikey.aspx) |
| **Books** | كتب | Open Library (بدون مفتاح) + Google Books (مفتاح مجاني اختياري). النتائج مدمجة — Google Books أولاً، ثم Open Library. |
| **Games** | ألعاب | RAWG (مفتاح مجاني مطلوب — [rawg.io/apidocs](https://rawg.io/apidocs)) + Steam (لا يوجد). النتائج مدمجة — RAWG أولاً، ثم Steam. |
| **Deezer** | موسيقى (ألبومات) | لا يوجد |
| **AniList** | أنمي | لا يوجد — واجهة AniList GraphQL API مجانية، لا حاجة لمفتاح |
| **Comic Vine** | كوميكس | مفتاح مجاني مطلوب — [comicvine.gamespot.com/api](https://comicvine.gamespot.com/api/) |

## الخصوصية واستخدام الشبكة

المكتبة **offline أولاً**: مكتبتك مجرد ملاحظات عادية وتواصل العمل دون اتصال. لا ترسل الإضافة إلا البيانات المذكورة أدناه، وفي هذه الحالات فقط:

- **عندما تتصرف بنفسك:** تبحث عن عنوان، أو تحدّث البيانات الوصفية، أو تشغّل أمرًا من أوامر AniList، أو تنقر على زر المشاركة.
- **عندما تفتح ملاحظة من المكتبة:** تُحدَّث بياناتها الوصفية من مصدرها عبر `Source ID`، مرة واحدة على الأكثر كل 5 دقائق لكل ملاحظة؛ أما الملاحظة التي لا تحتوي على `Source ID` فيُبحث عنها باسمها.
- **بعد تحديث الإضافة أو تغيير مفتاح API:** تمرّ عملية في الخلفية مرة واحدة على ملاحظات مكتبتك وتحدّثها من مصادرها، ملاحظة تلو الأخرى.

تُحمَّل صور الأغلفة واللقطات ومشغلات المقاطع الدعائية التي تشير إليها ملاحظاتك من الخوادم المذكورة أدناه.

لا تخرج أي بيانات أخرى من مكتبتك أبدًا. الإضافة **بلا تحليلات، بلا أتمتة، وبدون آلية تحديث ذاتي**. مفاتيح API (OMDb، Google Books، RAWG، Comic Vine، TMDB) مخزنة فقط في إعدادات الإضافات المحلية ولا تُرسل إلا إلى خدماتها الخاصة. تُحمّل صور الأغلفة مباشرة من عناوين URL التي تُرجعها كل مصدر.

## مخطط البيانات الأمامية

تقرأ الإضافة وتكتب إلى بيانات YAML الأمامية القياسية. يتم إنشاء الملاحظات لك، لكن كل حقل قابل للتعديل. `Source` و `Source ID` يسمحان للإضافة بتحديث البيانات الوصفية لاحقًا.

### فيلم

> **خاصية الغلاف** — يمكن تغيير خاصية frontmatter التي تخزّن الغلاف من **الإعدادات ← Library** (مثلًا إلى `image`)؛ ستبقى الملاحظات الحالية تعمل.

```yaml
---
Type: Movie
Name: Inception
Year: 2010
Genre:
    - "[[Action]]"
    - "[[Sci-Fi]]"
Creator:
    - "[[Christopher Nolan]]"
Cast:
    - "[[Leonardo DiCaprio]]"
    - "[[Joseph Gordon-Levitt]]"
    - "[[Elliot Page]]"
Rating IMDB: 8.8
Rating RT: 87
Runtime: 148
My Rating: 9
Cover: https://m.media-amazon.com/images/...
URL: https://www.imdb.com/title/tt1375666/
Trailer: https://www.youtube.com/watch?v=YoHD9XEInc0
Gallery:
    - https://image.tmdb.org/t/p/w780/9e3Dz7H1J0s5cBZLX2yXKxkC7Jg.jpg
Progress: 1/1
Complete: true
Date: 01.03.2026
Source: omdb
Source ID: tt1375666
---
```

## روابط الرسم البياني

تُحفظ الأنواع والمبدعون، وفي الأفلام والمسلسلات الممثلون، روابطَ في خصائصها الخاصة:

```yaml
Genre:
    - "[[Action]]"
    - "[[Sci-Fi]]"
Creator:
    - "[[Christopher Nolan]]"
Cast:
    - "[[Leonardo DiCaprio]]"
```

لذلك تعرض ملاحظة كل نوع ومبدع وممثل جميع أعماله في الروابط الخلفية، ويربط الرسم البياني الملاحظات من خلالها. تتحول الأسماء العادية — المكتوبة يدويًا أو المتبقية من إصدار سابق — إلى روابط كلما تغيّرت الملاحظة؛ ويبقى الرابط ذو الاسم المستعار كما هو. يحوّل `إعادة بناء روابط الرسم البياني` المكتبة كلها دفعة واحدة. لم تعد خاصية `Related` من الإصدارات السابقة مستخدمة، وتُزال من الملاحظات.

## المشاركة

تحصل كل ملاحظة محتوى على زر **مشاركة** في ترويستها (أو نفّذ أمر `مشاركة الملاحظة الحالية`). يعرض صورة بطاقة — الملصق، العنوان، السنة، النوع، تقييم IMDb/AniList، وتقييمك الخاص — يمكنك نشرها في أي مكان:

- **على الهاتف المحمول** — يفتح زر **مشاركة…** ورقة المشاركة الأصلية في جهازك مع إرفاق صورة البطاقة مباشرة، حتى يمكنك إرسالها فورًا إلى أي تطبيق.
- **X، Telegram، Reddit، WhatsApp، Facebook، LinkedIn، VK، Bluesky، Pinterest** — يفتح محرّر المنشور الخاص بالشبكة مع تعليق مُعبّأ مسبقًا (العنوان، تقييمك، رابط المصدر، ورابط إلى هذه الإضافة). تُنسخ صورة البطاقة إلى حافظتك في الوقت نفسه، فما عليك سوى لصقها (Ctrl/Cmd+V) في المنشور.
- **نسخ الصورة / نسخ النص / حفظ الصورة** — انسخ البطاقة المعروضة أو التعليق إلى الحافظة، أو احفظ الصورة في مجلد المرفقات بمخزنك لإرفاقها يدويًا.

المشاركة محلية بالكامل: تُرسم البطاقة داخل التطبيق من البيانات الوصفية والغلاف الخاصين بالملاحظة نفسها. لا يُرفع أي شيء — تفتح الإضافة فقط رابط محرّر المنشور الذي تختاره في متصفحك.

## مزامنة AniList

أبقِ تقدّم الأنمي لديك متزامنًا مع حساب [AniList](https://anilist.co) الخاص بك.

**الإعداد** — في **الإعدادات > المكتبة > مزامنة AniList**:

1. سجّل عميل API مجانيًا على [anilist.co/settings/developer](https://anilist.co/settings/developer)، مع ضبط رابط إعادة التوجيه على `https://anilist.co/api/v2/oauth/pin`.
2. الصق **Client ID**، وانقر على **اتصال**، وامنح التصريح.
3. يعرض لك AniList رمز وصول — الصقه في الإضافة. انقر على **اختبار الاتصال** للتأكيد.

ثم استخدم الأوامر:

- **Push current note to AniList** — يرسل تقدّم ملاحظة الأنمي النشطة (الحلقات المشاهدة)، والحالة (قيد المشاهدة / مكتمل / مخطط له)، وتقييمك إلى قائمة AniList الخاصة بك.
- **Pull progress from AniList** — يجلب قائمة أنمي AniList الخاصة بك ويحدّث الملاحظات المطابقة. السحب **أحادي الاتجاه (للأمام فقط)**: لا يتراجع أبدًا بملاحظة أنت متقدم فيها محليًا أو مكتملة بالفعل، ويترك تقييمك الشخصي `My Rating` دون تغيير.

تُزامَن فقط الملاحظات التي تحمل `Source: anilist` (المضافة عبر مصدر أنمي AniList). يُخزَّن رمزك محليًا في إعدادات الإضافة ولا يُرسَل إلا إلى AniList.

## الأوامر

| الأمر | الوصف |
| --- | --- |
| `فتح المكتبة` | فتح علامة تبويب معرض المكتبة. |
| `إضافة محتوى` | ابحث في مصدر وأنشئ ملاحظة محتوى (أو اكتب عنوانًا لليدوي). |
| `ابحث في مكتبتك` | ابحث بضبابية وافتح أي ملاحظة موجودة بالفعل في مكتبتك. |
| `تحديث البيانات الوصفية للملاحظة الحالية` | أعد جلب البيانات الوصفية للملاحظة النشطة؛ يحدث إجمالي حلقات المسلسل. |
| `إعادة بناء روابط الرسم البياني` | يحوّل `Genre` و`Creator` و`Cast` إلى روابط في كل ملاحظات المحتوى. |
| `البحث عن التكرارات وإزالتها` | افحص جميع الملاحظات حسب الرابط، اعرض التكرارات، وأزل المحددة. |
| `مشاركة الملاحظة الحالية` | اعرض الملاحظة كصورة بطاقة وشاركها على X أو Telegram أو Reddit أو WhatsApp أو Facebook أو LinkedIn أو VK أو Bluesky أو Pinterest. |
| `دفع الملاحظة الحالية إلى AniList` | أرسل تقدّم ملاحظة الأنمي النشطة وحالتها وتقييمها إلى حساب AniList الخاص بك. |
| `سحب التقدّم من AniList` | اجلب قائمة AniList الخاصة بك وحدّث الملاحظات المطابقة (للأمام فقط). |
| `تحديث البيانات الوصفية لكل الملاحظات` | جلب البيانات الوصفية لكل الملاحظات في المكتبة، واحدة تلو الأخرى في الخلفية. |
