## විශේෂාංග

- මාතෘකාවක් සොයා පෝස්ටරය, වර්ෂය, ප්‍රභේදය, නිර්මාණකරුවන්, නළු නිළියන් සහ ශ්‍රේණිගත කිරීම් පුරවා ඇති සටහනක් ලබා ගන්න.
- ඕනෑම භාෂාවකින් කෘති සොයාගත හැක: රුසියානු හෝ ජපන් මාතෘකාවකින් එහි චිත්‍රපටය, ක්‍රීඩාව හෝ කොමික් එක හමු වේ. මාතෘකාවට පසු වර්ෂයක් (`brother 1997`) පොදු නමක් පටු කරයි.
- පුස්තකාලය කවර කාඩ්පත් ලෙස බලන්න, ප්‍රවර්ගය අනුව කාණ්ඩ කර නම, වර්ෂය, ශ්‍රේණිගත කිරීම හෝ දිනය අනුව පිළිවෙළට.
- ඔබ තවම ආරම්භ නොකළ කෘතිවල කවරයේ ඇසක් ඇති අතර ඒවා පිටුවේ අවසානයේ **ඊළඟට** කොටසට එකතු වේ.
- නැමූ ප්‍රවර්ගයක් එහි කාඩ්පත් පැත්තට අනුචලනය වන එක් පේළියක පෙන්වයි.
- කතාමාලාවක කථාංග හෝ පොතක පරිච්ඡේද සලකුණු කර එකිනෙකට ලකුණු දෙන්න; `Progress` සහ `My Rating` ඒවායින් ගණනය වේ.
- චිත්‍රපට, කතාමාලා, ඇනිමේ සහ ක්‍රීඩා සටහන්වල ට්‍රේලරය සහ දර්ශන ඇත; චිත්‍රපට සහ කතාමාලාවල දිග සහ කන්න ලැයිස්තුව ද ඇත.
- සෑම සටහනක් යටම ඔබට තවම නැති සමාන මාතෘකා ඇත; එක් ක්ලික් කිරීමකින් එක් කළ හැක.
- Steam වෙතින් ඔබේ ක්‍රීඩා ක්‍රීඩා කළ පැය සමඟ ආයාත කරන්න.
- ප්‍රභේද, නිර්මාණකරුවන් සහ නළු නිළියන් සබැඳි වන නිසා ඔවුන්ගේ සටහන් සෑම මාතෘකාවක්ම පසු-සබැඳි සහ ප්‍රස්ථාරය තුළ එකතු කරයි.
- සංඛ්‍යාලේඛන පුවරුව ඔබ තෝරන ඉහළම ලැයිස්තු සහ මුළු නැරඹුම් කාලය පෙන්වයි.
- මාතෘකාවක් කාඩ්පත් රූපයක් ලෙස X, Telegram, Reddit සහ තවත් ජාල හයක බෙදාගන්න.
- ඇනිමෙ ප්‍රගතිය AniList සමඟ සමමුහුර්ත කරන්න.
- අතුරුමුහුණත Obsidian සහාය දක්වන සියලු භාෂාවලට පරිවර්තනය කර ඇති අතර, මෙම README [භාෂා 30කින්](./) ඇත.

## ඉක්මන් ආරම්භය

1. **Library** සැකසුම් → තුන්වන පාර්ශවීය ප්ලගිනය → පිරික්සන්න හරහා හෝ [GitHub Releases](https://github.com/Kigrok/obsidian-library-plugin/releases) වෙතින් ස්ථාපනය කරන්න.
2. සැකසුම් → Library තුළ එක් එක් අන්තර්ගත වර්ගය සඳහා ප්‍රවර්ගයක් එක් කරන්න: චිත්‍රපට, මාලා, පොත්, කොමික්, ක්‍රීඩා, සංගීතය, ඇනිමේ, අතින්.
3. රිබනයෙන් "පුස්තකාලය" ටැබය විවෘත කර, **+** ඔබා, ප්‍රවර්ගයක් තෝරා මාතෘකාවක් සොයන්න. දැනටමත් පුස්තකාලයේ ඇති මාතෘකාවක් එහි පවතින සටහන විවෘත කරයි.

ප්‍රවර්ගයක `Type` අගය (උදා. `Movie`) එයට අයත් සටහන් තීරණය කරන අතර, එහි ෆෝල්ඩරය නව සටහන් යන තැන තීරණය කරයි. දෙකම ප්‍රවර්ගයේ සැකසුම්වල **උසස්** යටතේ ඇත.

යතුරු සැකසුම් → Library → API යතුරු හි ඇතුළත් කරන්න.

ට්‍රේලර්, දර්ශන, දිග සහ වාර ලැයිස්තු Cinemeta වෙතින් ද, Rotten Tomatoes ලකුණු Wikidata හෝ OMDb වෙතින් ද ලැබේ. [TMDB යතුරක්](https://www.themoviedb.org/settings/api) වාර ශ්‍රේණිගත කිරීම් සහ තවත් දර්ශන එක් කරයි.

ඔබේ ක්‍රීඩා ගෙන ඒමට සැකසුම්වල [Steam Web API යතුරක්](https://steamcommunity.com/dev/apikey) සහ Steam පැතිකඩ ඇතුළත් කර `Steam පුස්තකාලය ආයාත කරන්න` ධාවනය කරන්න. එය සෑම ක්‍රීඩාවකටම පැයවලින් `Playtime` සහිත සටහනක් සාදයි, නැවත ධාවනය කළ විට නව ක්‍රීඩා එක් කර පැය යාවත්කාලීන කරයි. පැතිකඩේ ක්‍රීඩා විස්තර පොදු විය යුතුය.

ක්‍රීඩා සටහන්වලට තිර රූ සහ ට්‍රේලරයක් ලැබේ. Twitch Client ID සහ Client Secret ඇතුළත් කළහොත් ට්‍රේලරය IGDB හරහා YouTube වෙතින් එයි ([dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) හි යෙදුමක් සාදන්න), නැතහොත් Wikidata හි ඇත්නම් එතැනින්, නැතහොත් ක්‍රීඩාවේ Steam ට්‍රේලරය.

පැරණි අනුවාදවල සටහන් ඒවායේ ප්‍රගතිය රඳවා ගනී. ඔබ කිසිවක් සලකුණු නොකරන තුරු, `Progress` ගණන දක්වා පළමු කථාංග නැරඹූ ලෙස පෙන්වයි.
