## คุณสมบัติหลัก

- **ตารางการ์ดภาพ** — แท็บคลังสมบัติเฉพาะจะแสดงคอลเลกชันของคุณเป็นแกลเลอรีการ์ดปกศิลปะ
- **ค้นหาในตัว** — ค้นหาและเพิ่มชื่อเรื่องตรงในแอป: OMDb สำหรับภาพยนตร์และซีรีส์ Open Library หรือ Google Books สำหรับหนังสือ RAWG/Steam สำหรับเกม Deezer สำหรับเพลง AniList สำหรับแอนิเมะ Comic Vine สำหรับการ์ตูน
- **การติดตามซีรีส์อัจฉริยะ** — จำนวน_season และตอนถูกดึงโดยอัตโนมัติและรักษาการซิงค์
- **ตัวบ่งชี้ความคืบหน้า** — แถบความคืบหน้าภาพบนการ์ดและส่วนหัวบันทึกแสดงว่าคุณดูหรืออ่านไปมากน้อยเพียงใด
- **ส่วนหัวบันทึกที่หลากหลาย** — บันทึกเนื้อหาทุกรายการจะได้รับส่วนหัวที่สร้างโดยอัตโนมัติพร้อมข้อมูลเมตาหลักทั้งหมด
- **ตัวอย่าง ภาพนิ่ง และซีซัน** — โน้ตภาพยนตร์และซีรีส์แสดงตัวอย่าง YouTube/Vimeo แบบฝัง แถวภาพนิ่ง และความยาว ส่วนซีรีส์ยังมีรายการซีซันพร้อมจำนวนตอน คะแนน และตัวอย่างของแต่ละซีซัน
- **หมวดหมู่ที่กำหนดเอง** — สร้างหมวดหมู่สำหรับภาพยนตร์ ซีรีส์ แอนิเมะ การ์ตูน หนังสือ เกม เพลง หรือสิ่งอื่นใดผ่านแหล่งข้อมูลด้วยตนเอง
- **ลิงก์กราฟ** — แนว ผู้สร้าง และนักแสดงถูกเก็บเป็นลิงก์ในพร็อพเพอร์ตี `Genre` `Creator` และ `Cast` ของตัวเอง ดังนั้นโน้ตของแต่ละแนว ผู้สร้าง และนักแสดงจะรวบรวมผลงานไว้ในลิงก์ย้อนกลับ และกราฟแสดงทั้งหมด
- **การ์ดแชร์** — เปลี่ยนบันทึกเนื้อหาใดๆ ให้เป็นรูปการ์ดที่แชร์ได้ (โปสเตอร์ ชื่อเรื่อง ปี ประเภท คะแนน IMDb และคะแนนของคุณ) แล้วโพสต์ไปยัง X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky หรือ Pinterest — แชร์ตรงไปยังแอปในอุปกรณ์ของคุณ หรือคัดลอก/บันทึกรูปเพื่อใช้ที่ใดก็ได้
- **ซิงค์ AniList** — ส่งความคืบหน้า สถานะ และคะแนนแอนิเมะของคุณตรงไปยังบัญชี AniList ของคุณ หรือดึงรายการของคุณกลับเข้ามาในบันทึก
- **การจัดเรียงและการพับ** — เรียงการ์ดตามชื่อ ปี คะแนน หรือวันที่ และพับหมวดหมู่ใดก็ได้ — หมวดหมู่จะยังพับอยู่แม้รีสตาร์ต
- **สถิติ** — เลือกคอลัมน์เองได้: ผลงานที่ได้คะแนนสูงสุดของหมวดหมู่ใดก็ได้ หรือค่าที่พบบ่อยที่สุดของพร็อพเพอร์ตีใดก็ได้ (แนว ผู้สร้าง นักแสดง…) พร้อมแผนภูมิเวลาที่ดู
- **การตรวจจับซ้ำ** — ป้องกันการเพิ่มชื่อเรื่องเดียวกันสองครั้งโดย URL โดยอัตโนมัติ คำสั่งในตัวจะค้นหาและลบรายการที่ซ้ำกัน
- **หลายภาษา** — อินเทอร์เฟซของปลั๊กอินแปลเป็น **ทุกภาษาที่ Obsidian รองรับ** (70+) จึงตรงกับภาษาของ Obsidian ของคุณเสมอ และมี README ฉบับแปลเต็มสำหรับ 30 ภาษา (ดูแถบภาษาด้านบน)

## เริ่มต้นใช้งานอย่างรวดเร็ว

### 1. การติดตั้ง

ติดตั้ง **คลังสมบัติ** จาก [ไดเรกทอรีปลั๊กอินชุมชน Obsidian](https://community.obsidian.md/plugins/library) (การตั้งค่า > ปลั๊กอินชุมชน > เรียกดู > ค้นหา "คลังสมบัติ") หรือติดตั้งด้วยตนเองผ่าน [GitHub Releases](https://github.com/Kigrok/obsidian-library-plugin/releases)

### 2. การตั้งค่าเบื้องต้น

1. ไปที่ **การตั้งค่า** > **คลังสมบัติ**
2. เพิ่ม **หมวดหมู่** ของคุณ — เลือกประเภทที่กำหนดไว้ล่วงหน้า (ภาพยนตร์ ซีรีส์ หนังสือ การ์ตูน เกม เพลง แอนิเมะ หรือด้วยตนเอง) จากเมนูแบบเลื่อนลงและคลิก **เพิ่มหมวดหมู่** แต่ละหมวดหมู่มีชื่อที่แสดง (แปลเป็นภาษาของคุณ) ค่า `Type` (เป็นภาษาอังกฤษเสมอ เช่น `Movie`) แหล่งข้อมูล และโฟลเดอร์สำหรับเก็บบันทึก (ไม่บังคับ)
3. _（ไม่บังคับ）_ ป้อน API key สำหรับบริการที่คุณใช้: [OMDb](https://www.omdbapi.com/apikey.aspx) สำหรับภาพยนตร์/ซีรีส์ [RAWG](https://rawg.io/apidocs) สำหรับเกม [Comic Vine](https://comicvine.gamespot.com/api/) สำหรับการ์ตูน [TMDB](https://www.themoviedb.org/settings/api) สำหรับตัวอย่าง ภาพนิ่ง และข้อมูลซีซัน [Google Books](https://console.cloud.google.com/apis/library/books.googleapis.com) สำหรับค้นหาหนังสือ แอนิเมะ (AniList) เพลง (Deezer) และ Steam ไม่ต้องใช้ key

### 3. เพิ่มการ์ดด้วยชื่อเรื่อง

ไม่ต้องกรอก frontmatter ด้วยตนเองอีกต่อไป — เพิ่มภาพยนตร์ ซีรีส์ หนังสือ แอนิเมะ หรือการ์ตูนเพียงแค่ค้นหาชื่อ:

1. เปิดแท็บ **คลังสมบัติ** จากไอคอนริบบิ้น (หรือรัน `เปิดคลัง`)
2. คลิกปุ่ม **+** ที่มุมบนขวาของหน้าคลังสมบัติ (หรือรัน `เพิ่มเนื้อหา`)
3. เลือกหมวดหมู่ พิมพ์ **ชื่อเรื่อง** ในช่องค้นหา และเลือกผลลัพธ์
4. การ์ดถูกสร้างทันที โดยมีโปสเตอร์ ปี ประเภท ผู้สร้าง และคะแนนถูกกรอกโดยอัตโนมัติ

ปุ่ม **ค้นหา** ข้าง **+** จะค้นหาชื่อเรื่องที่มีอยู่ในคลังสมบัติของคุณแล้ว

สำหรับหมวดหมู่ **ด้วยตนเอง** คุณเพียงแค่พิมพ์ชื่อเรื่องและกรอกปก ปี และฟิลด์อื่นๆ ด้วยตนเอง

## สถิติ

ด้านบนของแท็บคลัง ส่วน **สถิติ** ที่พับได้จะแสดงคอลัมน์ที่คุณเลือก:

- **อันดับของหมวดหมู่** — ผลงานสามอันดับแรกที่ได้คะแนนสูงสุดของหมวดหมู่ พร้อมปก: *ภาพยนตร์ยอดนิยม*, *หนังสือยอดนิยม* เป็นต้น เรียงตาม `My Rating` หากไม่มีจะใช้ `Rating IMDB`
- **อันดับของพร็อพเพอร์ตี** — สามค่าที่พบบ่อยที่สุดของพร็อพเพอร์ตีทั่วทั้งคลัง: *แนวยอดนิยม*, *ผู้สร้างยอดนิยม*, *นักแสดงยอดนิยม* หรือพร็อพเพอร์ตีอื่นใด เช่น *ยอดนิยม: Author* โดย `Sci-Fi`, `sci-fi` และ `[[Sci-Fi]]` นับเป็นค่าเดียวกัน
- **เวลาที่ดู** — แผนภูมิชั่วโมงที่ใช้ไปกับภาพยนตร์ ซีรีส์ และอนิเมะ คำนวณจาก `Runtime` และ `Progress` ของแต่ละบันทึก

ตั้งค่าได้ที่ **ตั้งค่า → Library → สถิติ**: **เพิ่มอันดับ** จะแสดงหมวดหมู่ของคุณและพร็อพเพอร์ตีที่พบในบันทึก ไอคอนถังขยะใช้ลบคอลัมน์ และสวิตช์ใช้ซ่อนแผนภูมิเวลาที่ดู คอลัมน์จะเรียงตามลำดับที่เพิ่ม และหมวดหมู่ใหม่จะเพิ่มอันดับของตัวเองให้ด้วย

หมวดหมู่ที่พับไว้จะยังพับอยู่หลังรีสตาร์ต

## การตรวจจับซ้ำ

คลังสมบัติป้องกันรายการที่ซ้ำกันโดยการตรวจสอบฟิลด์ `URL`:

- **เมื่อเพิ่ม** — หากมีบันทึกที่มี URL เดียวกันอยู่แล้ว จะเปิดบันทึกที่มีอยู่แทนการสร้างซ้ำ
- **ค้นหาและลบรายการที่ซ้ำกัน** — รันคำสั่งนี้จาก palette เพื่อสแกนบันทึกทั้งหมด จัดกลุ่มตาม URL และลบรายการที่ซ้ำกันอย่างเลือกผ่าน modal

## แหล่งข้อมูล

แต่ละหมวดหมู่เชื่อมต่อกับแหล่งข้อมูลที่ขับเคลื่อนการค้นหา:

| แหล่งข้อมูล     | ประเภทเนื้อหา   | API key                                                      |
| ---------------- | --------------- | ----------------------------------------------------------- |
| **OMDb**         | ภาพยนตร์ ซีรีส์  | ต้องใช้ key ฟรี — [omdbapi.com](https://www.omdbapi.com/apikey.aspx) |
| **Books**        | หนังสือ          | Open Library (ไม่ต้องใช้ key) + Google Books (key ฟรีทางเลือก) ผลลัพธ์รวมกัน — Google Books ก่อน Open Library ด้านล่าง |
| **Games**         | เกม              | RAWG (ต้องใช้ key ฟรี — [rawg.io/apidocs](https://rawg.io/apidocs)) + Steam (ไม่ต้องใช้) ผลลัพธ์รวมกัน — RAWG ก่อน Steam ด้านล่าง |
| **Deezer**       | เพลง (อัลบั้ม)   | ไม่ต้องใช้                                                    |
| **AniList**        | แอนิเมะ          | ไม่ต้องใช้ — API GraphQL ของ AniList ฟรี ไม่ต้องใช้ key       |
| **Comic Vine**   | การ์ตูน          | ต้องใช้ key ฟรี — [comicvine.gamespot.com/api](https://comicvine.gamespot.com/api/) |
| **ด้วยตนเอง**    | สิ่งอื่นใด       | ไม่ต้องใช้ — คุณพิมพ์ชื่อเรื่องและกรอกฟิลด์เอง          |

โน้ตภาพยนตร์และซีรีส์สามารถเสริมข้อมูลด้วย **TMDB** (คีย์ฟรีแบบไม่บังคับ): ตัวอย่าง ภาพนิ่ง ความยาว และรายการซีซันของซีรีส์จะถูกดึงและเขียนลง frontmatter ของโน้ต

## ความเป็นส่วนตัวและการใช้เครือข่าย

Library ทำงานแบบ**ออฟไลน์เป็นหลัก** ไลบรารีของคุณเป็นเพียงโน้ตธรรมดาและใช้งานได้แม้ไม่มีการเชื่อมต่อ ปลั๊กอินจะส่งเฉพาะข้อมูลที่ระบุไว้ด้านล่าง และเฉพาะในกรณีต่อไปนี้เท่านั้น:

- **เมื่อคุณทำเอง:** ค้นหาชื่อเรื่อง รีเฟรชข้อมูลเมตา เรียกใช้คำสั่ง AniList หรือกดปุ่มแชร์
- **เมื่อคุณเปิดโน้ตในไลบรารี:** ข้อมูลเมตาของโน้ตจะถูกรีเฟรชจากแหล่งที่มาด้วย `Source ID` ไม่เกินหนึ่งครั้งทุก 5 นาทีต่อโน้ต ส่วนโน้ตที่ไม่มี `Source ID` จะถูกค้นหาจากชื่อ
- **หลังอัปเดตปลั๊กอินหรือเปลี่ยนคีย์ API:** กระบวนการเบื้องหลังจะรีเฟรชโน้ตในไลบรารีจากแหล่งที่มาหนึ่งครั้ง ทีละโน้ต

ภาพปก ภาพนิ่ง และเครื่องเล่นตัวอย่างที่โน้ตของคุณอ้างถึงจะโหลดจากโฮสต์ที่ระบุไว้ด้านล่าง

| บริการ | เมื่อใด | ส่งอะไร | ทำไม |
| --- | --- | --- | --- |
| `www.omdbapi.com` | ค้นหาหมวดหมู่ที่ใช้ OMDb | ชื่อเรื่องที่คุณพิมพ์และ OMDb API key ของคุณ | ดึงข้อมูลเมตาภาพยนตร์/ซีรีส์ (ปี ประเภท นักแสดง คะแนน โปสเตอร์ จำนวนตอน) |
| `openlibrary.org` | ค้นหาหมวดหมู่ Open Library | ชื่อเรื่องที่คุณพิมพ์ | ดึงข้อมูลเมตาหนังสือ (ผู้เขียน ปี หัวข้อ cover id) |
| `covers.openlibrary.org` | การ์ดหนังสือมีปก | cover id ของ Open Library | โหลดรูปปก |
| `www.googleapis.com` | ค้นหาหมวดหมู่ Google Books | ชื่อเรื่องที่คุณพิมพ์และ Google Books key ของคุณ | ดึงข้อมูลเมตาหนังสือ (ผู้เขียน ปี ประเภท จำนวนหน้า ปก ISBN) |

## ลิงก์กราฟ

แนว ผู้สร้าง และนักแสดงของภาพยนตร์และซีรีส์ ถูกเก็บเป็นลิงก์ในพร็อพเพอร์ตีของตัวเอง:

```yaml
Genre:
    - "[[Action]]"
    - "[[Sci-Fi]]"
Creator:
    - "[[Christopher Nolan]]"
Cast:
    - "[[Leonardo DiCaprio]]"
```

ดังนั้นโน้ตของแต่ละแนว ผู้สร้าง และนักแสดงจะแสดงผลงานทั้งหมดในลิงก์ย้อนกลับ และกราฟเชื่อมโน้ตผ่านสิ่งเหล่านี้ ชื่อธรรมดาที่พิมพ์เองหรือหลงเหลือจากเวอร์ชันก่อนจะกลายเป็นลิงก์ทุกครั้งที่โน้ตเปลี่ยน ส่วนลิงก์ที่มีชื่อแทนจะคงไว้ตามเดิม `สร้างลิงก์กราฟใหม่` แปลงทั้งไลบรารีในครั้งเดียว พร็อพเพอร์ตี `Related` ของเวอร์ชันก่อนไม่ได้ใช้แล้วและจะถูกลบออกจากโน้ต

## การแชร์

บันทึกเนื้อหาทุกรายการจะมีปุ่ม **แชร์** ในส่วนหัว (หรือรัน `แชร์โน้ตปัจจุบัน`) ซึ่งจะเรนเดอร์รูปการ์ด — โปสเตอร์ ชื่อเรื่อง ปี ประเภท คะแนน IMDb/AniList และคะแนนของคุณ — ที่คุณสามารถโพสต์ได้ทุกที่:

- **บนมือถือ** — ปุ่ม **แชร์…** จะเปิดชีตแชร์ในตัวของอุปกรณ์พร้อมแนบรูปการ์ดโดยตรง คุณจึงสามารถส่งไปยังแอปใดก็ได้ทันที
- **X, Telegram, Reddit, WhatsApp, Facebook, LinkedIn, VK, Bluesky, Pinterest** — จะเปิดตัวเขียนโพสต์ของเครือข่ายพร้อมคำบรรยายที่กรอกไว้ล่วงหน้า (ชื่อเรื่อง คะแนนของคุณ ลิงก์ต้นฉบับ และลิงก์ไปยังปลั๊กอินนี้) รูปการ์ดจะถูกคัดลอกไปยังคลิปบอร์ดของคุณในเวลาเดียวกัน คุณจึงเพียงแค่วาง (Ctrl/Cmd+V) ลงในโพสต์
- **คัดลอกรูป / คัดลอกข้อความ / บันทึกรูป** — คัดลอกการ์ดที่เรนเดอร์หรือคำบรรยายไปยังคลิปบอร์ด หรือบันทึกรูปลงในโฟลเดอร์ไฟล์แนบของ vault เพื่อแนบด้วยตนเอง

การแชร์เป็นแบบท้องถิ่นทั้งหมด: การ์ดถูกวาดในแอปจากข้อมูลเมตาและปกของบันทึกเอง ไม่มีการอัปโหลดอะไร — ปลั๊กอินเพียงเปิด URL ตัวเขียนโพสต์ที่คุณเลือกในเบราว์เซอร์ของคุณเท่านั้น

## ซิงค์ AniList

ทำให้ความคืบหน้าแอนิเมะของคุณซิงค์กับบัญชี [AniList](https://anilist.co) ของคุณอยู่เสมอ

**การตั้งค่า** — ใน **การตั้งค่า → คลังสมบัติ → การซิงก์ AniList**:

1. ลงทะเบียน API client ฟรีที่ [anilist.co/settings/developer](https://anilist.co/settings/developer) โดยตั้งค่า redirect URL เป็น `https://anilist.co/api/v2/oauth/pin`
2. วาง **Client ID** คลิก **เชื่อมต่อ** และให้สิทธิ์
3. AniList จะแสดง access token ให้คุณ — วางลงในปลั๊กอิน คลิก **ทดสอบการเชื่อมต่อ** เพื่อยืนยัน

จากนั้นใช้คำสั่ง:

- **Push current note to AniList** — ส่งความคืบหน้า (ตอนที่ดูแล้ว) สถานะ (กำลังดู / ดูจบ / วางแผนจะดู) และคะแนนของคุณจากบันทึกแอนิเมะที่ใช้งานอยู่ไปยังรายการ AniList ของคุณ
- **Pull progress from AniList** — ดึงรายการแอนิเมะ AniList ของคุณและอัปเดตบันทึกที่ตรงกัน การดึงข้อมูลเป็นแบบ **เดินหน้าอย่างเดียว**: จะไม่ย้อนกลับบันทึกที่ในเครื่องคืบหน้าไปมากกว่าหรือดูจบแล้ว และจะไม่แตะต้อง `My Rating` ส่วนตัวของคุณ

เฉพาะบันทึกที่มี `Source: anilist` (เพิ่มผ่านแหล่งข้อมูลแอนิเมะ AniList) เท่านั้นที่จะถูกซิงค์ token ของคุณถูกเก็บไว้ในการตั้งค่าปลั๊กอินท้องถิ่นและส่งไปยัง AniList เท่านั้น

| `ดึงความคืบหน้าจาก AniList`         | ดึงรายการ AniList ของคุณและอัปเดตบันทึกที่ตรงกัน (เดินหน้าอย่างเดียว) |
| `รีเฟรชข้อมูลเมตาสำหรับหมายเหตุทั้งหมด` | ดึงข้อมูลเมตาของทุกโน้ตในไลบรารี ทีละรายการในเบื้องหลัง |
