## Возможности

- **Визуальная сетка карточек** — Вкладка «Библиотека» отображает коллекцию как галерею обложек.
- **Встроенный поиск** — Ищите и добавляйте произведения прямо в приложении: OMDb для фильмов и сериалов, Open Library или Google Books для книг, RAWG для игр, Deezer для музыки, Jikan для аниме, Comic Vine для комиксов.
- **Умный подсчёт серий** — Сезоны и количество серий подтягиваются автоматически и синхронизируются.
- **Индикаторы прогресса** — Визуальные полоски прогресса на карточках и заголовках заметок показывают, сколько вы посмотрели или прочитали.
- **Информативные заголовки** — Каждая заметка получает автоматически сгенерированный заголовок со всеми ключевыми метаданными.
- **Пользовательские категории** — Создавайте категории для фильмов, сериалов, аниме, комиксов, книг, игр, музыки или чего угодно через ручной ввод.
- **Связи графа** — Свойство `Related` во фронтматере связывает каждую заметку с категорией, жанрами и создателями, автоматически обновляясь для красивого графа.
- **Сортировка и свёртывание** — Сортируйте карточки по названию, году, рейтингу или дате; сворачивайте любую категорию.
- **Статистика** — Топ жанров, топ создателей (только фильмы и сериалы) и топ произведений по категориям с медалями.
- **Поиск дубликатов** — Автоматически предотвращает повторное добавление одного произведения по URL. Встроенная команда находит и удаляет существующие дубликаты.
- **Мультиязычность** — 31 язык.

## Быстрый старт

### 1. Установка

Установите **Library** из каталога плагинов Obsidian (Настройки > Плагины сообщества > Обзор > поиск «Library») или вручную через [GitHub Releases](https://github.com/Kigrok/obsidian-library-plugin/releases).

### 2. Настройка

1. Перейдите в **Настройки** > **Library**.
2. Добавьте **категории** — выберите готовый тип (Фильмы, Сериалы, Книги, Комиксы, Игры, Музыка, Аниме или Вручную) из выпадающего списка и нажмите «Добавить категорию». Каждая категория имеет отображаемое имя (на вашем языке), значение `Type` (всегда английское, например `Movie`), источник и необязательную папку для хранения заметок.
3. _(Необязательно)_ Введите API-ключи для нужных сервисов: [OMDb](https://www.omdbapi.com/apikey.aspx) для фильмов/сериалов, [RAWG](https://rawg.io/apidocs) для игр, [Comic Vine](https://comicvine.gamespot.com/api/) для комиксов. Для аниме (Jikan) и музыки (Deezer) ключ не нужен.

### 3. Добавление карточки по названию

Больше не нужно заполнять фронтматер вручную — добавьте фильм, сериал, книгу, аниме или комикс просто по названию:

1. Откройте вкладку **«Библиотека»** по иконке в ленте (или командой «Открыть библиотеку»).
2. Нажмите кнопку **+** в правом верхнем углу (или команду «Добавить контент»).
3. Выберите категорию, введите название в поисковую строку и выберите результат.
4. Карточка создаётся мгновенно — постер, год, жанр, создатели и рейтинг заполняются автоматически.

Кнопка **«Поиск»** рядом с + ищет уже добавленные произведения.

Для категорий **«Вручную»** просто введите название и заполните обложку, год и другие поля сами.

## Статистика

Вкладка «Библиотека» включает сворачиваемый раздел **«Статистика»** вверху:

- **Топ жанров** — по частоте встречаемости во всей библиотеке.
- **Топ создателей** — по количеству фильмов и сериалов.
- **Топ по категориям** — для каждой категории — топ-3 по рейтингу с маленькими обложками.

---

## Поиск дубликатов

Library предотвращает дублирование, проверяя поле `URL`:

- **При добавлении** — если заметка с таким URL уже существует, открывается существующая вместо создания дубликата.
- **Найти и удалить дубликаты** — запустите эту команду из палитры для сканирования всех заметок, группировки по URL и выборочного удаления.

## Источники

Каждая категория привязана к источнику, который обеспечивает поиск:

| Источник | Типы контента | API-ключ |
| --- | --- | --- |
| **OMDb** | Фильмы, Сериалы | Нужен бесплатный ключ — [omdbapi.com](https://www.omdbapi.com/apikey.aspx) |
| **Books** | Книги | Open Library (без ключа) + Google Books (необязательный бесплатный ключ). Результаты объединяются. |
| **RAWG** | Игры | Нужен бесплатный ключ — [rawg.io/apidocs](https://rawg.io/apidocs) |
| **Deezer** | Музыка (альбомы) | Без ключа |
| **Jikan** | Аниме | Без ключа — бесплатное неофициальное API MyAnimeList |
| **Comic Vine** | Комиксы | Нужен бесплатный ключ — [comicvine.gamespot.com/api](https://comicvine.gamespot.com/api/) |
| **Вручную** | Любое | Без ключа — вводите название и заполняете поля сами |

## Конфиденциальность и сеть

Library работает **автономно**. Плагин обращается к сети только при активном поиске произведения и только с введённым запросом:

| Сервис | Когда | Что отправляется | Зачем |
| --- | --- | --- | --- |
| `www.omdbapi.com` | Поиск по OMDb | Название и API-ключ | Метаданные фильмов/сериалов |
| `openlibrary.org` | Поиск по Open Library | Название | Метаданные книг |
| `covers.openlibrary.org` | У книги есть обложка | ID обложки | Загрузка изображения |
| `www.googleapis.com` | Поиск по Google Books | Название и ключ | Метаданные книг |
| `api.rawg.io` | Поиск игр по RAWG | Название и ключ | Метаданные игр |
| `api.deezer.com` | Поиск музыки по Deezer | Альбом или исполнитель | Метаданные альбомов |
| `api.jikan.moe` | Поиск аниме | Название | Метаданные аниме |
| `comicvine.gamespot.com` | Поиск комиксов | Название и ключ | Метаданные комиксов |

Больше никакие данные не покидают ваше хранилище. Плагин не имеет телеметрии, аналитики и автообновления. API-ключи хранятся только в локальных настройках и отправляются только соответствующим сервисам.

## Схема фронтматера

Плагин читает и записывает стандартный YAML-фронтматер. Заметки создаются автоматически, но каждое поле можно отредактировать. `Source` и `Source ID` позволяют плагину обновлять метаданные позже.

### Фильм

```yaml
---
Type: Movie
Name: Начало
Year: 2010
Genre:
    - боевик
    - фантастика
Creator:
    - Кристофер Нолан
Rating IMDB: 8.8
My Rating: 9
Cover: https://m.media-amazon.com/images/...
URL: https://www.imdb.com/title/tt1375666/
Progress: 1/1
Complete: true
Date: 01.03.2026
Source: omdb
Source ID: tt1375666
---
```

### Сериал

```yaml
---
Type: Series
Name: Stranger Things
Year: 2016
End Year: 2025
Season: 5
Genre:
    - драма
    - фэнтези
    - ужасы
Creator:
    - Братья Даппер
Rating IMDB: 8.7
My Rating: 9
Cover: https://m.media-amazon.com/images/...
URL: https://www.imdb.com/title/tt4574334/
Progress: 25/42
Complete: false
Date: 01.03.2026
Source: omdb
Source ID: tt4574334
---
```

> **Автообновление сериалов:** Запустите «Обновить метаданные для текущей заметки» (или просто откройте заметку) — плагин обновит общее количество серий в `Progress` и количество сезонов, сохранив ваш счётчик просмотренных.

### Книга

```yaml
---
Type: Book
Name: Дюна
Year: 1965
Genre:
    - научная фантастика
Creator:
    - Фрэнк Герберт
Cover: https://covers.openlibrary.org/b/id/...-L.jpg
ISBN: 9780441013593
My Rating: 9
Progress: 412/688
Complete: false
Date: 01.03.2026
Source: openlibrary
Source ID: /works/OL893415W
---
```

### Аниме

```yaml
---
Type: Anime
Name: Steins;Gate
Year: 2011
Genre:
    - фантастика
    - триллер
Creator:
    - シュタインズ・ゲート
Rating MAL: 9.07
Total Episodes: 24
Status: Finished Airing
Cover: https://cdn.myanimelist.net/images/anime/...
URL: https://myanimelist.net/anime/9253/Steins_Gate
Progress: 0/24
Complete: false
Date: 01.03.2026
Source: jikan
Source ID: 9253
---
```

### Комикс

```yaml
---
Type: Comic
Name: Watchmen
Year: 1986
Genre:
    - Комиксы
Creator:
    - DC Comics
Cover: https://comicvine.gamespot.com/a/uploads/...
URL: https://comicvine.gamespot.com/watchmen/4050-33819/
Progress: 0/12
Complete: false
Date: 01.03.2026
Source: comicvine
Source ID: 33819
---
```

## Связи графа

Каждая заметка получает свойство `Related` во фронтматере, которое обновляется автоматически — тело заметки никогда не затрагивается:

```yaml
Related:
    - "[[Movie]]"
    - "[[Action]]"
    - "[[Sci-Fi]]"
    - "[[Christopher Nolan]]"
```

Эти связи объединяют заметки через общие категории, жанры и создателей, формируя чистые кластеры в графе Obsidian. Для каждой категории создаётся реальная заметка-хаб (например, `Movie`), чтобы кластеры отображались даже со скрытыми неразрешёнными ссылками.

## Команды

| Команда | Описание |
| --- | --- |
| `Открыть библиотеку` | Откройте вкладку «Библиотека». |
